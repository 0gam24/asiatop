## 1. 지금 측정값 (2026-10-07)

### 1-1. 빈틈 글의 네이버 색인과 순위

공식 웹문서 검색 API, 깊이 30. "색인"은 글 제목을 그대로 검색했을 때 그 글이 결과에 나오는지로 확인했다.

| 묶음 | 편수 | 색인됨 | 노린 검색어 10위 안 | 30위 안 |
|---|---|---|---|---|
| 빈틈 글 2026-09-17 ~ 09-28 (발행 후 9~20일) | 12 | 12 | 0 | 1 (청년미래적금 자동이체 15위) |
| 빈틈 글 2026-09-29 ~ 10-07 (발행 8일 이내) | 5 | 측정 중 | 0 | 0 |

- 2026-09-30 순위 기록(`docs/revenue-log/naver-rank-history.json`)의 추적 검색어 49개 중 10위 안은 4개다.
  부양가족 소득기준 300만원 1위, 연말정산 일정 2027년 1월 4위, 근로장려금 35% 선지급 5위, 피부양자 소득요건 2000만원 9위. 넷 다 숫자가 들어간 검색어다.
- 웹문서 API 순위는 통합검색 화면의 순위와 다르다(docs/26 §2). 실제 노출·클릭은 서치어드바이저 자료로만 안다. 그 자료는 아직 없다.
- 순위 기록은 2026-09-30 이후 자동으로 쌓이지 않았다(예약 실행 없음).

### 1-2. 검색량

- 오늘 대기열의 proposed 25건 중 데이터랩 30일 검색량(실업급여 = 100 눈금)이 0보다 큰 항목은 6건이다. 나머지 19건은 데이터랩이 0으로 준다.
- 데이터랩은 작은 검색어를 0으로 준다. 0은 "검색 없음"이 아니라 "이 눈금으로 안 잡힘"이다. 검색 수 절대값은 아직 없다.
- 네이버 검색광고 API 의 키워드 도구(`/keywordstool`)는 키워드별 월간 검색 수(PC·모바일)와 연관 키워드를 준다. 키는 검색광고 계정에서 약관 동의 즉시 발급된다(2026-10-07 확인). 아직 발급하지 않았다.

### 1-3. 주제별 수익

- 머니룩 글·주제별 1000회당 수익: 확인 안 됨. 애드센스 관리 API 의 PAGE_URL 보고서가 머니룩에 대해 0행을 준다.
- awoo 의 운영자 제공 페이지별 자료(비공개)에서는 주제 묶음 사이 1000회당 수익 차이가 컸다. 머니룩이 쓰는 주제(세금·일·청년 저축)는 그 자료에서 낮은 쪽 묶음이었다. 머니룩 값은 확인 안 됨.

### 1-4. 유입 경로

- 구글 서치 콘솔 2026-09-29 ~ 10-04 하루 클릭 0~3.
- 네이버 유입: 확인 안 됨(서치어드바이저·네이버 애널리틱스는 공개 API 가 없다). 사이트에는 네이버 애널리틱스(wcslog)와 GA4 태그가 설치돼 있다(2026-10-07 라이브 확인).

## 2. 측정에서 바로 나오는 결론

1. 색인은 막히지 않았다. 노린 검색어의 순위가 막혀 있다.
2. 지금 빈틈 점수(자리 열림·빈자리·관공서 없음·지식iN 같은 질문 수)로 고른 12편 가운데 9~20일 안에 10위 안에 든 글은 없다. 이 점수를 그대로 둔 채 편수만 늘릴 근거가 없다.
3. 빈틈 검색어 대부분은 실제 검색 수를 모른다. 1위를 해도 몇 명이 오는지 모른다.
4. 머니룩 주제별 1000회당 수익을 모른다.
5. 단계 올리기 조건(직전 14일 신규 글 중 30위 안 30% 이상, 10위 안 1편 이상)은 지금 값으로 충족되지 않는다.

그래서 첫 일은 편수를 늘리는 것이 아니라 **무엇이 실제로 순위와 클릭과 수익을 내는지 재는 것**이다.

### 3-2. 결과 기록 장치 (Claude)

- `targetQuery` 가 있는 글 전부를 매일 공식 웹문서 API 로 재서 순위를 쌓는다. 발행 후 3·7·14·28일 표를 만든다.
- 대기열 항목의 점수 요소(빈자리·관공서·지식iN·검색량)와 결과(순위·클릭)를 한 표로 묶는다.
- 검색광고 API 키가 오면 대기열 항목마다 월간 검색 수를 붙이는 스크립트를 만든다.

### 3-3. 고르는 규칙 고치기 (자료가 쌓인 뒤, 측정 근거로만)

- **월간 검색 수 하한**: 검색광고 API 값과 서치어드바이저 클릭을 맞대어 정한다. 정하기 전에는 하한을 쓰지 않는다.
- **순위에 든 글의 공통점**: 지금 10위 안 4개는 모두 숫자가 든 검색어다. 표본이 4개라 아직 규칙으로 쓰지 않는다.
- **주제 수익 배수**: 3-1 #4 자료로 머니룩 주제 묶음별 상대 배수를 만든다. 공개 저장소에는 금액 없이 배수만 둔다.
- 바꾼 규칙은 5절에 날짜·근거와 함께 남긴다.

### 3-4. 매일 운영

- **목록** (`.claude/commands/목록.md`): 오늘 측정분 빈틈 글감, 다음에 크게 뜰 주제, [발행 지시]·[보류]·[눈 확인]·[선점] 버튼. 운영자가 "목록"이라고 하면 띄운다.
- **신규**: KST 09:05 루틴과 운영자 [발행 지시]가 같은 하루 상한(A단계 2편)을 나눠 쓴다.
- **리프레시**: 검색량이 오른 주제의 기존 글을 먼저 갱신한다(2026-09-07 실측: 급등 키워드 대부분이 이미 기존 글이 있는데 10위 밖이었다, docs/26).

### 3-5. 매주 점검 (월요일)

- 표: 하루 수익·조회·1000회당 수익과 목표까지 남은 배수(비공개 로그), 빈틈 글 10위·30위 안 편수, 서치어드바이저 클릭(자료가 있을 때).
