# 네이버 수요 리서치: 2026년 9~12월 (작성 2026-09-07 KST)

## 방법·출처 표기 규칙
- **AC** = 네이버 자동완성 API (`ac.search.naver.com/nx/ac?q=<씨앗>`) 실측. 씨앗 키워드 ~370개 (3회 배치), 원본 `research/ac/*.json`, 요약 `ac-results*.txt`.
- **KIN** = 지식iN 최신순 검색 (`kin.naver.com/search/list.naver?query=&sort=date`) 9/7 기준 질문 제목. 원본 `research/kin/*.html`.
- 네이버 통합검색 "함께 많이 찾는" 블록은 클라이언트 렌더링(fender/qra API 는 토큰 필요) 이라 curl 로 수집 불가 → **미확인**. 연관검색어는 AC 의 2차 확장(세부 키워드를 다시 씨앗으로 투입)으로 대체.
- 뉴스·go.kr 근거는 WebSearch 결과 URL. 검색 예산 소진(200/200) 으로 확인 못 한 항목은 "미확인" 표기.
- 기존글 대조는 `src/content/articles/*.mdx` grep (제목·본문 키워드) + 인벤토리 slug 기준.
- 제외: 정치성(주 52시간 폐지 논쟁), 투기성(청약 단지 일정·공모주·금리 전망), 예측성 소재.
