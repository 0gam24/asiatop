> 조건부 단계 증량 확정 — 신규 일 1편+시즌 자동승인 2편째(주 ≤9), 리프레시 주 10~14, 게이트 측정 정의 6건 전면 보정

# 발행 케이던스 최종 합의안 (2026-06-13 시행, R3 — 이의 반영 확정본)

세 이의(seo·content·growth)는 케이던스 골격이 아니라 **측정 정의의 결함**을 공통 표적으로 삼았고, 특히 G2 분모 게이밍(seo)·G4 선택 편향(content+growth 교차 지적)·트리아지 90일 기준의 정의상 불가능(seo)은 게이트를 형식화하거나 오발동시키는 실질 결함이므로 전면 반영한다. 골격(증량분은 리프레시에, 신규는 게이트식)은 세 이의 제기자 모두 수용했으므로 불변.

## 1. 결론 — 즉시 적용분 (6/13~)

| 트랙 | 즉시 적용 | 변경점 (초안 대비) |
|---|---|---|
| **신규** | **일 1편 기본 + 2편째 슬롯 자동승인제 — 주간 총량 ≤9편** (2편 발동 주 2회 상한) | 시즌 훅 루프홀 봉쇄(seo) + 자동승인 기준 명문화(growth) 동시 채택 |
| **리프레시** | **주 10편 목표(상한 14)** — 첫 2주는 10을 하한이 아닌 목표치로, 미달 페널티 없음 | 1일 표본 비대칭 단서 추가(content). 검증 품질 > 편수 |
| **미색인 트리아지** | **6/26까지 117편 분류(처분 결정) 100% → 7/3까지 통합·제거 실행+위생 완료** | 분류/실행 분리(content) + 위생 의무 포함(seo) |
| 기타 | `public/_headers` `/*.md` noindex 1줄 즉시 / 451 vs 411 미계상 ~40 URL 출처 규명(6/26까지, 분모 단일화) | ~40 URL 규명 신설(seo) |

**2편째 슬롯 자동승인 기준** (보수적 해석으로 일 1편 퇴화 방지 — growth 채택, 객관화 — seo 채택):
- ① `/topics`(gsc-opportunities.mjs)가 GSC 실측 노출 데이터로 제시한 키워드, **또는** ② 사전 합의 7월 세무 캘린더 목록(재산세 1기 7/16·부가세 확정 7/25·주민세 8월 — docs/23 §5-2 캘린더 준용)
- **AND** 카니발리제이션 대조 통과 + 판정 기록 audit 잔존 (둘 다 충족 시 별도 승인 절차 없이 자동 발동)
- 주간 신규 총량 ≤9편은 자동승인과 무관하게 절대 상한

**색인률의 단일 정의 (전 게이트·킬스위치 공통)**: `GSC URL 검사 확인 색인 수 ÷ 라이브 indexable 사이트맵 URL 수`. 410·301 처분 URL은 **URL 검사에서 제거·리다이렉트 인식이 확인된 후에만** 분모 제외. GSC 커버리지 보고서 수치는 보조 확인용. — seo의 분모 게이밍 차단과 growth의 커버리지 보고서 지연(수 주) 회피를 동시에 충족: 자체 재계산을 본선으로 하되 종이 위 분모 축소는 불가.

## 2. 단계별 증량 스케줄 + 측정 가능한 게이트

### Stage 0 — 즉시 (6/13~)

- 신규 일 1편 기본 + 자동승인 2편째 (§1 기준), 주 ≤9편.
- 리프레시 주 10 목표(상한 14). 우선순위: ①고위험 클러스터(credit-loan·insurance-personal·세금) ②스트라이킹 디스턴스(11~30위) ③7월 시즌 글. **단, 이 우선순위 큐의 오류 발견량은 게이트 입력값이 아니다** (§G4 참조 — 선택 편향 차단).
- 트리아지 ②(개선 후 재색인) 작업은 **주 10~14 리프레시 쿼터에 포함** (별도 트랙이면 실질 부하 2배로 주 20h 예산 충돌 — content 채택).

**트리아지 처분 기준 (seo 수정안 채택 — 기존 '90일 무노출' 기준은 451편 전부 발행 ~70일 미만이라 정의상 적용 불가)**:
- ③410/noindex 제거: **발행 후 45일+ 경과 AND 발행 이후 전 기간 노출 0·클릭 0**인 글만
- 기준 연령 미달(특히 6월 발행분): ②개선 후 재색인 또는 **④판정 유보(재심사일 명기)** — 무리한 조기 410 금지
- **처분 완료의 정의**: ①통합(301)·③410 시 사이트맵 즉시 제외 + 해당 URL을 가리키는 기존 글 내부링크(편당 3~5개 의무 링크 포함) 전수 교체까지. 누락 시 G1 미충족.
- 분류 100% = 6/26, ①③ 실행+위생 완료 = 7/3, ② 는 리프레시 큐 편입(재색인 요청 제출 시점 기준 완료)

### Stage 1 — 신규 일 2편 고정 (조건 전부 충족 시, 최속 7월 초~중순 — 유지)

| 게이트 | 내용 | 측정 규격 (R3 보정) |
|---|---|---|
| **G1** | 117편 트리아지 완료 | 분류 100%(④유보 포함 4분류) + ①③ 실행·위생 완료 + ② 큐 편입. 유보 글은 재심사일 명기 필수 |
| **G2** | 재계산 색인률 ≥75% **2주 연속** | §1 단일 정의(URL 검사 기반 자체 재계산). **신규 코호트 포함 상태로 충족** (seo). 커버리지 보고서 대기 불요 (growth) |
| **G3** | 신규 14일 코호트 색인률 ≥80% | **최소 표본 n≥10 — 미달 시 충족까지 측정 기간 연장**. GSC URL Inspection API 전수 검사 (일 1~2편이므로 전수 가능) |
| **G4** (재정의) | (a) **현행 파이프라인 산출물**(직전 2주 신규+리프레시 완료분) 사후 무작위 재검증 오류율 **<10%** AND (b) **레거시 무작위·층화 표본**(주 5편 고정, 우선순위 큐와 분리 추출) 오류율 **2주 연속 비상승** | 우선순위 큐 발견량(현재 3/3)은 게이트가 아니라 리프레시 우선순위 입력값으로만 사용 — content·growth 교차 지적 채택. (a)는 claims-guard 통과분의 누출률이므로 <20%보다 엄격한 <10% |
| **G5** | AdSense 정책 센터 무경고 유지 | 변경 없음 |

### Stage 2 — 신규 일 3편 검토 (D+45, 7월 말)

- 색인률 ≥80% **4주 연속** (§1 단일 정의)
- 신규 30일 코호트 색인률 ≥90% — **경성 게이트**
- 색인 소요 중앙값 **≤14일 — 보조 지표로 강등** (미달 시 검토 항목, 단독 차단 불가). ≤7일 경성 게이트는 월 6천 PV 사이트의 크롤 수요에 과잉 보정 (growth 채택, 단 완전 삭제는 기각 — §5)
- 실측 RPM이 증량을 정당화 (docs/23 §4-2 기존 게이트 보존)
- 주 20h 4주 연속 수렴 실증 + 주간 LLM 토큰 비용 4주 기록 후 월 상한 명문화 (policy 조건 보존)
- 통과 시에도 일 3편은 2주 관찰 후 고정 (단계식)

### 불변 품질 게이트 (한 줄도 변경 금지 — 이의 반영 정밀화 2건만)

- 전 편 1차 출처 웹검증 + claims-guard / 기명 저자 + lastReviewed, 무기명 신규 전면 금지 / 카니발리제이션 대조 / 클러스터 점유 ≤30%·고위험 주 1편 상한 — 전부 불변
- **(정밀화 1 — content)** 광고 위치 충돌 해소: **above-fold 광고 0개가 상위 규칙** — 첫 슬롯은 모바일 뷰포트 기준 첫 화면 밖 첫 구조 요소 뒤로. 'TL;DR/ToC 직후' 위치 규칙은 이 제약 하에서만 적용 (충돌 시 슬롯 강등)
- **(정밀화 2 — content, docs/21 §4-2 준용)** updatedAt = 본문 실질 변경 시에만 / lastReviewed = 출처·수치 확인 동반 시에만(단독 갱신 금지) / 본문 무변경 재검토 = dataValidAsOf만 갱신. **리프레시 편수 집계는 updatedAt 갱신 자격 편만 산입** — date stamping 차단과 쿼터 집계 혼선 방지를 동시에

### 인프라·측정 (초안 유지 + 1건 추가)

- 콘텐츠 PR 일 ≤2건 묶음 / CF 빌드 주 1회 점검 / 머지 직렬화 / IndexNow 신규+리프레시 양쪽 발사 검증 / 네이버 RSS 확인 — 전부 유지
- 측정 5종(주간 색인률·코호트·오류 audit·LLM 비용·운영 시간)에 **레거시 무작위 표본 추출 절차**(주 5편, `scripts/audit/` 패턴, 시드 기록으로 재현 가능) 추가 — G4(b) 입력값

## 5. 기각된 이의와 사유

1. **growth — "G2를 자체 재계산으로 정의하면 트리아지 완료(6/26) 즉시 75% 자동 충족" → 부분 기각.** 자체 재계산 본선화는 채택하나, 처분 URL의 분모 제외는 **GSC URL 검사에서 410·리다이렉트 인식 확인 후에만** 인정한다. 무조건 즉시 제외를 허용하면 seo가 지적한 분모 게이밍(410 명령만으로 79.3% 도달)과 동전의 양면이 된다. URL 검사 인식은 커버리지 보고서(수 주)와 달리 재크롤 후 수일~2주 내 확인 가능하므로 Stage 1 최속 시점(7월 초~중순)은 실제로 보존된다 — growth가 우려한 'D+45로의 사실상 후퇴'는 발생하지 않는다.
2. **growth — "Stage 2 색인 소요 중앙값 게이트는 사문화 위험이므로 삭제(보조 강등 또는 ≤14일 완화 중 택일 요구에서 삭제 쪽 해석)" → 부분 기각.** 삭제가 아니라 **≤14일 + 보조 지표 강등을 동시 적용**한다. 색인 소요는 scaled content 사이트에서 크롤 수요 악화를 가장 먼저 보여주는 시그널이므로 측정 자체는 보존할 가치가 있다. 단독 차단 불가이므로 사문화 우려는 해소된다.
3. **growth — "오류는 폐기된 자동 파이프라인의 레거시 재고 품질이므로 게이트와 무관" (G4에서 레거시 완전 배제 함의) → 부분 기각.** 킬스위치의 현행 산출물 한정은 채택하나, 레거시도 **현재 색인·광고 게재 중인 라이브 YMYL 자산**이므로 G4(b) 무작위 표본 추세 조건(2주 연속 비상승)으로 게이트에 잔존시킨다. 수준(level)이 아닌 추세(trend) 조건이므로 '스톡 부채가 Stage 1을 수개월 봉쇄'하는 growth의 우려는 발생하지 않는다.
4. **seo·content 이의 — 기각 0건.** 6건+5건 전부 채택 (일부는 growth 이의와 병합 조정).
