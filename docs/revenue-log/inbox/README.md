# inbox, 네이버 콘솔 내보내기 투입함

네이버 서치어드바이저와 네이버 애널리틱스는 **공개 API 가 없다**(2026-09-08 확인, 네이버 오픈 API 목록에
데이터랩·검색 API 만 존재). 그래서 노출·클릭 실측은 사람이 콘솔에서 내려받아 여기에 넣어야 한다.

## 넣는 방법 (월 1회 권장)

1. **서치어드바이저** (필수)
   searchadvisor.naver.com → 리포트 → 검색 노출/클릭 현황 → **검색어** 탭 → CSV 다운로드.
   기간은 최대 90일까지 조회된다. 문서 탭도 받으면 함께 넣어도 된다.
2. **네이버 애널리틱스** (선택)
   analytics.naver.com → 유입분석 → 검색어 → CSV 다운로드. 서치어드바이저와 교차 확인용.
3. 받은 파일을 이 폴더에 그대로 넣고 실행:

```bash
pnpm audit:console
```

컬럼 이름은 콘솔 버전마다 달라서 스크립트가 자동으로 찾는다(검색어·노출수·클릭수·클릭률·순위).
못 찾으면 헤더를 그대로 출력하니 그때 알려 주면 후보 목록에 추가한다.

## 결과

`docs/revenue-log/naver-console-YYYY-MM-DD.json` 이 생기고 콘솔에 개선 후보 3분류가 뜬다.

| 분류 | 뜻 | 다음 단계 |
|---|---|---|
| ① 노출은 되는데 클릭이 안 붙는다 | 검색 결과에 보이지만 안 눌린다. 제목·설명 문제 | docs/24 P4 트랙(제목·메타 전용 도구), 운영자 승인 필요 |
| ② 클릭은 나는데 우리 순위가 낮다 | 더 올릴 여지가 있다 | /topics 리프레시 후보 |
| ③ 수요는 있는데 우리 글이 없다 | 빈자리 | 1차 출처 확인 후 신규 후보 |

`글` 칸에 "매칭 불확실" 이 붙으면 검색어와 글을 기계가 확신하지 못한 것이니 사람이 확인한다.

## 이 폴더의 원본 파일은 커밋되지 않는다

`.gitignore` 에서 이 폴더를 제외했다(README 만 추적). 정규화된 JSON 요약만 커밋해 이력을 남긴다.
원본에는 우리 사이트의 검색 유입 데이터가 들어 있고 크기도 커서, 리포지토리에는 요약만 두는 편이 낫다.
