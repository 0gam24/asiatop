# 26. 네이버 최상단 노출 실행 계획 (2026-09-07)

운영자 지시: "NAVER API HUB 의 API(검색·검색어 트렌드)와 NCP MCP 를 가지고 이 사이트의 글이 네이버 검색 노출 최상단에 오르게 할
방안을 에이전트 팀으로 찾고 계획을 나열하라." docs/25(성장·회복 실행 계획)의 네이버 트랙을 구체화한 문서다.
docs/24 의 네이버 불변 원칙(robots·canonical·RSS·인증·IndexNow 변경 금지)과 캐던스(신규 일 1편 이하)는 여기서도 상위 제약이다.

## 0. 목표와 측정

- 목표: 핵심 금융 키워드에서 네이버 통합검색 **최상단** = 웹사이트 영역 1~3위, 스마트블록 편입, AI 브리핑 인용.
- 기준선(2026-09-07): 측정 324개 키워드 중 네이버 웹문서 10위 내 우리 글 5개(2%). 서치어드바이저 클릭 일 245, 색인 670/685.
- KPI(주 1회): `naver-serp` 의 `ourTop10`(5/30 기준선) · `naver-demand` 의 `ourRank` 보유 키워드 수(5 기준선) · 서치어드바이저 클릭·노출.
  CTR 은 애드센스 규칙상 관찰만.

## 2. 역설계에서 확인된 사실 (2026-09-07, 목표 키워드 30개, docs/revenue-log/naver-serp-2026-09-07.json)

| 항목 | 웹문서 상위 10 전체 | 상위 3 |
|---|---|---|
| 도메인 유형 | go.kr/or.kr 58% · 기타(정부24·나무위키·금융사·계산기) 34% · 언론 5% · 우리 2% · **블로그 0%** | 공식 61% · 기타 30% · 언론 7% · 우리 2% |
| 제목 길이 평균 | 30.8자 | 31.4자 |
| 제목에 숫자 포함 | 42% | 44% |
| 제목에 연도 포함 | 20% | 19% |
| 제목 질문형 | 8% | 4% |
| 설명 길이 평균 | 107.7자 | 106.4자 |

읽는 법:
1. 네이버 **웹사이트 영역은 블로그와 경쟁하지 않는다.** 경쟁자는 정부 페이지와 정부24·금융사·위키 같은 "서비스·정의 페이지"다.
2. 정부 페이지는 제도 일반론을 차지한다. 우리가 이미 10위 안에 든 5개("부양가족 소득기준 300만원" 1위, "연말정산 일정 2027년 1월" 3위,
   "피부양자 소득요건 2000만원" 5위, "근로장려금 35% 선지급" 6위, "종합부동산세 고지서 11월" 7위)는 전부 **확정 수치·날짜 + 상황**이
   박힌 롱테일이다. 정부 페이지가 비워 둔 "구체 상황"이 우리 자리다.
3. 상위 제목은 서술형 31자 안팎, 절반이 숫자를 담는다. 질문형은 제목이 아니라 **소제목·FAQ** 자리다(docs/21 의 H2 질문형 30~50% 규칙과 정합).
4. 설명(description)은 100~110자에서 끊긴다. 스키마 상한 170자보다 짧게, 첫 100자 안에 수치·기한을 넣는다.

트렌드에서 확인된 사실(137개 키워드에 값, 최근 4주÷직전 4주): 근로장려금 환수 8.3배·지급 조회 7.1배(9월 정기 지급 + 반기 신청),
청약통장 전환 방법 7.1배(9/30 마감), 고령 운전자 면허 갱신 4.5배(★ 기존 글 없음), 운전면허 적성검사 과태료 3.5배, 자동차세 연납 할인율 3.4배,
자동차 채권 환급 2.9배, 전월세 신고제 과태료 2.6배, 본인부담상한제 환급 2.5배. 급등 키워드의 대부분은 **기존 글이 있는데 그 글이 10위 밖**이다.
→ 신규보다 **급등 시점의 리프레시**가 최상단 진입의 가장 빠른 경로.

**통합검색 첫 화면 실측 (2026-09-07, 금융 질의 5건 HTML 관찰, docs/research/2026-09-07-naver-ai-timing.md §2)**: 블록 순서는
[광고] → [공공서비스 카드] → **AI 브리핑** → 알기 쉬운 공공 정보(공식 블로그) → 인플루언서 → 뉴스 → **웹사이트(공식 도메인 위주)** → 카페 → 지식iN → 블로그.
AI 브리핑은 5건 중 4건에 떴고 정보출처 13건 중 go.kr 9·독립 웹 1(awoo.or.kr)·위키 1·은행 1. 웹사이트 블록은 국세청·위택스·생활법령 같은 공식 도메인으로
채워져 **웹문서 API 순위와 첫 화면 노출은 다르다**(머니룩 근로장려금 글 3편이 웹문서 API 1~3위인데 첫 화면 0건). 독립 웹이 AI 브리핑에 인용된 유일한 사례는
"공식 문서가 직접 답하지 않는 질문(청년도약계좌 중도해지 손실·부분인출)"을 첫 문단에서 즉답하고 정부 링크 8건·FAQ 5건·실명 편집자를 갖춘 3,500자 글이었다.
→ 우리가 실제로 들어갈 자리는 **AI 브리핑 출처**, **웹사이트 블록(공식 문서가 비운 롱테일)**, 드물게 지식스니펫이며, 세 곳 모두 "질의별 신뢰 출처 우선" 랭킹(2025-09~)이
작동한다. 진입 조건은 (a) go.kr 원문 링크를 문단마다 (b) 공식 문서가 답하지 않는 지식iN 반복 질문을 첫 문단에서 즉답 (c) 즉답 1문장 → 소제목 2~3 → 불릿 구조.

## 3. 네이버용 문서 규격 (공식 가이드 + 역설계 실측, docs/research/2026-09-07-naver-ranking-factors.md)

**전제가 되는 공식 사실**: 2025-11-24 부터 네이버는 "문서 유형에 관계없이 신뢰할 수 있는 출처의 문서를 우선 노출"하는 신뢰도 중심 통합 랭킹을 적용 중이고,
출처 신뢰도는 AI 가 "특정 웹사이트가 어떤 성격의 출처인지, 사이트의 구성이나 내용이 신뢰할 만한지"를 판단한다. 독립 사이트도 판정 대상이며 재료는
사이트 메타 정보·본문·외부 참조 설명이다. 문서 단위 공식 원칙은 5가지(직접 경험한 지식, 일관된 주제, 거짓 없는 진정성과 원문 링크, 읽기 쉬운 구조, 최신성 유지)와
셀프 체크 5축(독자와 목적, 절차와 해결 과정, 대안 비교, 실제 적용 결과, 맥락 맞는 미디어)이다. AI 브리핑은 "기존 검색 결과에 잘 노출되는 양질의 글"을 인용하므로
통합검색 순위가 인용의 선행 조건이다.

- **제목**: 서술형 **25~35자(가이드 상한 40자)**, 같은 키워드 2회 이상 반복 금지, 페이지별 고유. 공식 = **제도명 + 확정 수치·날짜 + 상황**.
  예) "재산세 2기분 9월 30일까지, 250만원 넘으면 분납 가능", "피부양자 소득 2,000만원 넘으면 12월 1일 지역가입자 전환".
  네이버는 "검색 노출만을 위한 잦은 제목 변경"을 스팸으로 본다. 기존 글 제목 불변 원칙·풋프린트 가드는 그대로.
  제목 공식 5종: ① 수치 조건형 ② 일정 기한형 ③ 질문 답변형(얼마·언제·어떻게) ④ 대상 조건형 ⑤ 비교형.
- **설명(description)**: 1~2문장, **80자 이하(서치어드바이저 진단 기준)**. 본문 복사·제목 중복·전 페이지 동일 설명 금지, 키워드 1회.
  검색 결과에 보이는 스니펫은 100~110자로 잘리지만 그것은 AI 스니펫이 본문에서 뽑는 길이이고, 메타 설명 자체는 80자 규칙을 따른다.
- **첫 문단(BLUF 3문장, 150~250자)**: ① 질의를 주어로 한 정의·직답 1문장(60~90자, 스니펫 추출 단위) ② 핵심 수치·기한 + 기준일 + 출처 기관명
  ③ 누구에게 해당하는지. 지식iN 반복 질문 중 공식 문서가 답하지 않는 것을 여기서 답한다.
- **본문(H2 4~7개, 질문형 30~50%)**: ① 핵심 조건 표(항목·금액·기준·근거 조문, 표 전후 산문 docs/12 §2-6-b) ② 절차 리스트 5~8단계(기한·준비물)
  ③ 계산 예시 1~2개(독창 요소) ④ 대안·비교와 상황별 권장 ⑤ 자주 틀리는 점 3~5개 ⑥ FAQ 3~5문항 ⑦ 출처·확인일 ⑧ 갱신 이력(실변경 시에만).
  길이 2,500~4,000자. 이미지 1~2장, alt 는 설명문, 이미지 핵심은 텍스트로도.
- **신뢰 신호**: 인용마다 원문 링크와 확인일, 저자·검토자 표기, 광고 게재 사실 고지. 외부 링크는 1차 출처만(홍보성 외부 URL 과다는 지양 항목).

## 4. 타이밍 규칙 (트렌드 곡선 실측 기반, docs/research/2026-09-07-naver-ai-timing.md §3)

실측값: 네이버 공식 "로봇 방문 후 최대 1주일 내 반영". 머니룩 실측 색인 지연 **L ≈ 3~4일**(9/4 글 → 9/7 site: 5위), 일반 질의 순위 진입 **R ≈ 1~2주**
(8/25 글 → 13일 뒤 1위). 2025년 곡선: 근로장려금 반기신청은 8/28(안내문)·9/1(개시) 2봉 후 9/6 에 11 로 급락, 재산세는 9/12(고지서 도착) 39 → 9/30(마감) 100,
연말정산 미리보기는 개통 주(11/5) 34 → 12월 3주 56 의 2차 상승. 즉 **마감형은 개시·마감 2봉, 개통형은 개통 주 + 연말 2차**이고 피크 4~5일 뒤 수요의 70% 가 사라진다.

```
P = 관심도 피크일 (전년 곡선의 피크를 올해 제도 앵커 = 신청 개시·고지서 발송·마감·개통 에 맞춰 이동)
신규 글   : 발행일 ≤ P − (L + R)  →  P−14 ~ P−10
리프레시  : 수정일 ≤ P − L        →  P−7 ~ P−4   (본문 실질 변경 시에만, 무변경 날짜 갱신 금지)
2봉 일정  : 개시일 P1·마감일 P2 각각 적용. "마감 D-N" 문구는 P2−7 이후 리프레시에서만.
창을 놓쳤으면 신규를 내지 않고 다음 앵커(마감일) 리프레시로 이월한다 (피크 이후 신규는 남은 수요 30% 이하).
```

- 발표형(요율·개편 발표): 발표 당일~D+3 리프레시. 트리거는 `newsPerDay` 급등.
- 상시형(정의·절차): 트렌드 무관, 지식iN 질문 수(`kinTotal`)로 우선순위.
- 검증 루프: 발행 D+3 에 웹문서 API `site:` 색인 확인, D+7·D+14 에 `naver-demand` 의 `ourRank`. 둘 다 0 이면 다음 시즌 L·R 을 늘린다.
- 전년 곡선 절차(월 1회, 달력 갱신과 함께): 앵커 키워드 3~5개를 한 그룹으로 `timeUnit: date`, 전년 앵커 ±6주 조회 → 피크일·상승 시작일(피크의 30%)·2봉·반감기 기록
  → 올해 앵커로 이동(요일 보정) → `trendRatio` 로 "지금 이미 오르는가" 교차 확인 → 달력 `bestPublishWindow` 갱신.

   (ETF·펀드·가상자산·증권·경제지표·부동산 시세)은 웹문서 자리가 줄었으므로 신규 주제에서 제외. 클러스터 허브에서 하위 글로 내부링크 정리.
3. **서치어드바이저 진단 정합**: 신규 글과 운영자 지정 리프레시 글에 제목 40자·설명 80자·키워드 반복 0·페이지별 고유 설명을 게이트로 추가.
