### 핵심만 30초

- **정부24·PASS·토스 무료 발급** — 주민센터 방문 600원과 달리 모두 무료.
- **3가지 앱 모두 효력 동일** — 정부 표준 PDF 동일 양식.
- **주민번호 마스킹 선택 가능** — 보안용도는 마스킹, 금융기관 제출은 비마스킹.
- **인쇄·이메일 모두 가능** — PDF 다운로드 후 자유롭게 활용.
- **유효기간 90일** — 발급 후 90일 내 사용 (기관별 30~60일 요구하기도).

</div>

## 주민등록등본 모바일, 어디서 발급할 수 있나요?

3개 주요 앱 모두 무료 모바일 발급 지원([행정안전부](https://www.mois.go.kr) 전자정부 안내).

| 앱 | 특징 |
|---|---|
| **정부24** | 정부 공식, 200+ 민원 통합 |
| **PASS** | 통신사 인증 기반, 빠른 인증 |
| **토스** | 금융 앱 부가 서비스, UX 친화 |

세 앱 모두 발급 효력 동일. PDF 양식 표준화로 어디서 발급해도 같은 문서.

## 정부24 모바일 발급 절차

1. [정부24 앱](https://www.gov.kr) 다운로드 + 로그인
2. "민원서비스" → "주민등록등본"
3. 본인인증 (공동인증서·간편인증)
4. 주민번호 마스킹 선택 (예/아니오)
5. PDF 발급 + 다운로드
6. 카카오톡·이메일 공유 또는 인쇄

발급 시간: **3~5분** (인증 포함).

## PASS 발급, 어떻게 다른가요?

PASS는 **이동통신사 인증 기반**이라 통신사 가입자 한정([SKT/KT/LGU+ 통합 PASS](https://www.tworld.co.kr) 등).

장점:
- 본인 통신사 자동 인증 → 별도 인증서 X
- 30초 이내 인증
- 휴대폰 비밀번호로 생체 인증

단점:
- 통신사 미가입자(알뜰폰 일부) 사용 X
- 발급 가능 민원 정부24보다 적음

## 토스 발급은 어디서 찾나요?

토스 앱 → "전체 메뉴" → "전자증명서 발급".

토스 장점:
- UI 매우 직관적
- 금융 인증과 동일 흐름
- 발급 이력 자동 저장
- 주민등록등본 + 가족관계 + 운전경력 + 소득 등 통합

단점: 일부 민원은 미지원.

## 주민번호 마스킹, 언제 선택해야 하나요?

발급 시 마스킹 옵션 선택:

| 용도 | 권장 |
|---|---|
| 일반 행정 (학교·임대차) | **마스킹** (보안용) |
| 금융기관 (대출·계좌개설) | **비마스킹** (전체 표시 요구) |
| 부동산 거래 (등기 등) | 비마스킹 |
| 본인 보관용 | 마스킹 |

마스킹 형식: **000000-1******** (앞 6자리만 표시).

## 모바일 발급 등본, 인쇄해도 효력 있나요?

네, **인쇄본도 효력 동일**합니다(행정안전부 2024년 전자증명서 통합).

조건:
- PDF 원본 그대로 인쇄 (앞·뒤 정보 변형 X)
- 색상·폰트 정부 표준 양식
- QR 코드 명확히 표시 (검증용)

기관에서 의심 시 QR 코드로 위변조 검증 가능.

## 발급 후 유효 기간은?

행정안전부 표준: **발급일로부터 90일**.

다만 기관별 요구 기간이 다름:
- 금융기관: 30일 이내
- 임대차 계약: 60일 이내
- 학교: 90일 이내
- 공무원 응시: 발급일 기준 (당일 권장)

기관 제출 직전 발급이 안전. 90일 지나면 새로 발급.

## 가족 등본 발급, 본인이 받을 수 있나요?

본인 + 동일 세대원 등본만 발급 가능. 분리 세대 가족은:

1. 가족 본인이 직접 발급 (본인 명의 인증)
2. 가족이 본인에게 위임 → 위임장 + 신분증 사본
3. 주민센터 방문 시 동행 + 신분증 확인

모바일 발급은 **본인 단독**만 가능 — 위임 처리 X.

## 외국인등록사실증명서도 발급 가능한가요?

외국인은 별도 사이트:

- **외국인등록사실증명서**: 출입국·외국인청 [hikorea.go.kr](https://www.hikorea.go.kr)
- **국내거소신고사실증명**: 외교부 [Visit Korea](https://www.mofa.go.kr) 또는 hikorea

정부24 일부 외국인 민원도 지원 (영어 인터페이스 제한적).

## 모바일 vs 주민센터 방문 비교

| 항목 | 모바일 | 주민센터 |
|---|---|---|
| 비용 | **무료** | 600원 |
| 시간 | 3~5분 | 30분 (대기 포함) |
| 운영시간 | **24/7** | 평일 9~18시 |
| 발급 매수 | 무제한 | 1매당 600원 |
| 위임 | 본인만 | 위임장 가능 |
| 첨부 | PDF 즉시 | 종이 1매 |

직장인은 모바일이 압도적 유리. 위임 발급 시만 주민센터.

## 발급 이력 추적

모바일 발급 시 본인 발급 이력이 자동 저장:

- 정부24: 마이페이지 → 발급이력 (1년 보관)
- PASS: 인증 이력 (30일)
- 토스: 발급함 (영구 보관)

본인이 누구에게 등본 발급해서 보냈는지 추적 가능.

## 자주 발생하는 오류와 해결

1. **본인인증 실패**: 통신사 인증 차단 → PC 인증으로 변경
2. **PDF 다운로드 안 됨**: 브라우저 다른 것 시도 (Chrome 권장)
3. **인쇄 시 양식 깨짐**: A4 100% 비율 + "맞춤" 옵션 해제
4. **QR 검증 실패**: 발급 90일 초과 → 재발급

---

주민등록등본은 모바일 발급이 무료, 24/7, 3분으로 압도적 유리합니다. 정부24·PASS·토스 중 평소 사용하는 앱에서 즉시 발급 가능. 한 번 발급해두면 카카오톡으로 즉시 공유까지 가능해 직장 일정 중에도 간편합니다.
