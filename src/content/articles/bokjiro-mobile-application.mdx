### 핵심만 30초

- **200여 복지 사업 통합 신청** — 청년월세·기초연금·아동수당·국민기초생활·한부모 등 한 앱에서.
- **본인인증 5분** — 공동인증서·간편인증·PASS 등.
- **모의계산 무료** — 본인 자격·예상 수령액 미리 확인.
- **신청 진행 확인** — 마이페이지에서 처리 단계 실시간 추적.
- **앱 + 웹 모두 동일** — [bokjiro.go.kr](https://www.bokjiro.go.kr) 또는 모바일 앱.

## 복지로, 정확히 뭔가요?

복지로는 **보건복지부가 운영하는 통합 복지 포털**입니다([보건복지부](https://www.mohw.go.kr)). 정부 부처·지자체 모든 복지 사업을 한 곳에서 신청·조회 가능.

특징:
- 약 200여 복지 사업 통합 (정부24보다 복지 특화)
- 모바일 앱 + 웹 동일 기능
- 모의계산 + 신청 + 진행 상황 추적
- 본인 + 가족 자격 모두 확인

직장인이 자주 이용하는 사업: 청년월세지원, 청년도약계좌, 한부모가족, 자녀장려금, 기초연금(부모님), 아동수당.

## 복지로 신청 5단계

기본 신청 절차:

1. **앱 다운로드 또는 웹 접속** ([bokjiro.go.kr](https://www.bokjiro.go.kr))
2. **본인인증** (공동인증서·카카오·네이버·PASS)
3. **자격 모의계산** — "맞춤형 복지서비스" 메뉴
4. **신청서 작성** — 자격 충족 사업 클릭 후 신청
5. **진행 상황 확인** — 마이페이지에서 단계별 추적

평균 신청 5~10분.

## 모의계산, 어떻게 쓰나요?

복지로의 가장 강력한 기능. 본인 정보 입력만으로 **수십 개 사업 자격 자동 판정**(보건복지부 2025).

이용:
1. 복지로 → "맞춤형 복지서비스" → "복지급여 모의계산"
2. 가구 정보 입력 (가구원 수, 소득, 재산)
3. 자동으로 **자격 충족 사업 목록** 출력
4. 사업별 예상 수령액 표시
5. 신청 가능한 사업 즉시 신청

흔히 본인이 모르고 못 받던 복지 발견. 청년 직장인도 30~40개 사업 자격 갖는 경우 흔함.

## 신청 가능한 주요 사업 목록

직장인·청년 자주 이용 사업:

| 사업 | 자격 | 지원 |
|---|---|---|
| 청년월세지원 | 만 19~34세 무주택 | 월 20만원 × 12개월 |
| 청년도약계좌 | 만 19~34세 소득 7,500만 이하 | 5년 5천만 |
| 자녀장려금 | 부부 합산 4,000만 미만 | 자녀 1인 최대 100만 |
| 한부모 양육비 | 중위소득 60% 이하 | 월 21만원/자녀 |
| 기초연금 (부모) | 만 65세 이상 소득하위 70% | 월 약 40만원 |
| 아동수당 | 만 8세 미만 자녀 | 월 10만원 |

## 본인인증 어떻게 하나요?

[복지로](https://www.bokjiro.go.kr)에서 5가지 인증 방법 지원.

| 인증 방법 | 절차 |
|---|---|
| 공동인증서 (구 공인) | 인증서 + 비밀번호 |
| 카카오 인증 | 카카오톡으로 인증 알림 |
| 네이버 인증 | 네이버 앱 인증 |
| PASS 인증 | PASS 앱 자동 인증 |
| 토스 인증 | 토스 앱 인증 |

본인인증만 가능 — 가족 대신 신청 시 별도 위임 필요.

## 신청 후 처리 기간은?

사업별 처리 기간 다름(보건복지부 2025).

| 사업 | 처리 기간 |
|---|---|
| 자녀장려금 | 약 30~45일 |
| 청년월세지원 | 약 60~90일 |
| 한부모가족 | 약 30~45일 |
| 기초연금 | 약 30~60일 |
| 아동수당 | 약 14~30일 |

빠른 처리: 자동 자격 판정 가능한 사업 (아동수당 등). 느린 처리: 소득·재산 검토 필요한 사업 (청년월세).

## 진행 상황 확인 방법

복지로 → 마이페이지 → "신청 진행 상황":

| 단계 | 의미 |
|---|---|
| 접수 | 신청 완료 |
| 검토 중 | 자격 심사 진행 |
| 추가 자료 요청 | 보완 서류 필요 |
| 결정 | 승인 또는 반려 |
| 지급 | 본인 계좌 지급 |

추가 자료 요청 시 알림 → 빠른 응답 권장. 응답 늦으면 자동 반려 가능.

## 신청 후 거부되면?

거부 사유 통보 → 다음 옵션:

1. **재신청** (자격 충족 시점 다시 도래 시)
2. **이의신청** (60일 이내, 보건복지부 또는 지자체)
3. **행정심판** (이의 거부 시 90일 이내)

흔한 거부 사유: 소득 초과, 재산 초과, 가구원 수 변동, 거주 요건 미충족.

## 다른 복지 통합 사이트와 어떻게 다른가요?

| 사이트 | 특징 |
|---|---|
| **복지로** | 복지 사업 200+ 통합, 모의계산 강점 |
| 정부24 | 행정·민원 통합 (복지 일부) |
| 고용24 | 고용·실업급여 특화 |
| 홈택스 | 세금·세무 특화 |

복지 신청은 **복지로 1순위**. 일부 사업(예: 청년월세지원)은 정부24·복지로 모두 가능.

## 모바일 앱 vs 웹, 어느 게 편한가요?

| 환경 | 장점 |
|---|---|
| 모바일 앱 | 푸시 알림, PASS 자동 인증, 사진 첨부 |
| 웹 | 큰 화면, 자료 다량 입력, 인쇄 |

직장인 자투리 시간 신청은 모바일 앱, 본격적 신청·자료 정리는 웹.

## 가족 단위 신청 어떻게 하나요?

본인이 가족 동의 후 대표 신청:

1. 본인 인증 (대표자)
2. 가구원 추가 (가족관계증명서 자동 조회)
3. 가구원 동의 (PASS 인증으로 즉시 가능)
4. 가구원 정보 자동 반영

가족 모두 PASS 인증 가능하면 5분이면 끝.

---

복지로 모바일은 정부 복지 사업의 마스터키입니다. 직장인도 청년 시기 + 자녀 + 부모님 사업 합치면 연 200~500만원 수령 가능. 가입 후 모의계산 한 번만 돌려봐도 본인이 놓치고 있던 복지 발견됩니다.
