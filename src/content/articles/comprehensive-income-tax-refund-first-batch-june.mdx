5월 종합소득세 환급금이 6월 말부터 입금 시작합니다. 5/25 이전 정상 신고한 분들이 1차 입금 대상. 입금 추적 + 즉시 노란우산 재투입으로 다음 해 환급액을 30~50% 키우는 절세 순환의 시작 시점입니다.

<div class="tldr">

### 핵심만 30초

- **첫 입금**: **6월 말 ~ 7월 초** (5/25 이전 신고자 기준)
- **추적 메뉴**: [홈택스](https://www.hometax.go.kr) \"환급금 조회\" 4단계 확인
- **입금 안 들어오면**: 계좌 오류 진단 + 정정 신청
- **즉시 활용**: 노란우산·연금저축·IRP 추가 납입 → 내년 환급 누적
- **5년 절세 순환**: 약 100~300만원 추가 절세 가능

</div>

본 글의 시점·절차는 국세청·국세기본법 운영 안내에 따라 변경될 수 있으니, 처리 전 [홈택스](https://www.hometax.go.kr) 와 [국세청](https://www.nts.go.kr) 공식 페이지를 재확인하시기 바랍니다. 본 글은 정보 제공 목적이며 세무 자문이 아닙니다.

## 환급 입금 시점 — 신고 시점별

5월 신고 시점별 환급 입금:

| 신고 시점 | 환급 입금 |
|-----------|-----------|
| 5/25 이전 | **6월 말 ~ 7월 초** |
| 5/26~28 | 7월 초 |
| 5/29~31 | 7월 중순 ~ 말 |
| 6월 자진 신고 (기한 후) | 7월 말 ~ 8월 |

오늘 6/4 기준:
- 5/25 이전 신고자 = 6월 말 첫 입금 (D-30 이내)
- 5/26~31 신고자 = 7월 초·중 (D-30~50)

## 추적 4단계 — 6월 첫 주 시점

홈택스 \"환급금 조회\" 단계별 의미:

| 단계 | 6/4 시점 정상 위치 (5/25 이전 신고자) |
|------|----------------------------------------|
| 접수 | (이미 통과) |
| **심사 중** | **✅ 현재 위치 가능성 높음** |
| 승인 | 6월 중순 진입 예상 |
| 입금 | 6월 말 ~ 7월 초 |

\"심사\" 단계 안 보이면 신고 누락 가능성 → 즉시 재확인.

## 환급 추적 — 단계별 정상 일정

오늘 본인 단계가 정상인지 점검:

- 5/15 이전 신고: \"승인\" 진입 또는 \"입금\" 임박
- 5/16~25: \"심사 중\" 정상
- 5/26~31: \"접수\" 또는 \"심사 진입\"
- 6월 자진 신고: \"접수\"

예상 단계보다 늦으면 진단 필요.

## 입금 안 들어올 때 — 5가지 사유

환급 안 들어오는 흔한 사유:

1. **계좌 오타** (가장 흔함, 80%+) - 신고서 입력 시 1자리 틀림
2. **폐쇄 계좌** - 작년 자동 호출 계좌가 폐쇄
3. **가족 명의 계좌** - 본인 명의 외 거부
4. **외화 계좌** - 원화만 가능
5. **동결 계좌** - 신용·세금 문제로 동결

특히 계좌 오타가 90% 차지.

## 정정 신청 — 즉시 4단계

위 5가지 사유 발견 시:

1. **홈택스 로그인** — [홈택스](https://www.hometax.go.kr)
2. **세금신고 → 환급 계좌 정정** 메뉴
3. **본인 명의 활성 원화 계좌 재입력**
4. **제출 + 처리 대기** (2~4주 추가)

빨리 정정 = 입금 빠름.

## 환급 입금 직후 — 즉시 활용 3가지

환급금 받자마자 즉시 활용:

### 1. 노란우산공제 추가 납입 (자영업자 1순위)
- 본인 소득공제 한도 (600만/500만/400만/200만)까지 채우기
- 내년 종합소득세 추가 환급
- 5년 누적 효과 큼

### 2. 연금저축·IRP 납입 (모든 소득자)
- 연 통합 900만원 한도
- 세액공제율 16.5% (총급여 5,500만 이하)
- 즉시 적용

### 3. 비상금 확보 (7월 보험료 대비)
- 자영업자 7월 보험료 인상분
- 분납 신청 사전 자금

소비 대비 절세 도구 재투입이 ROI 큼.

## 5년 누적 시뮬레이션 — 절세 순환

환급금 100만원 매년 노란우산 재투입 시:

| 연도 | 환급금 | 노란우산 누적 | 내년 환급 추가 |
|------|--------|---------------|-----------------|
| 2026 | 100만 | 100만 | +22만 |
| 2027 | 122만 | 222만 | +27만 |
| 2028 | 149만 | 371만 | +33만 |
| 2029 | 182만 | 553만 | +40만 |
| 2030 | 222만 | 775만 | +49만 |
| **합계** | — | **775만 부금** | **171만 추가 절세** |

5년 누적 약 170만 추가 절세 + 노란우산 부금 775만 (퇴직금 적립).

자세히는 머니룩의 [종소세 환급금 절세 순환](/tax/comprehensive-income-tax-refund-recycle-strategy/) 가이드 참고.

## 첫 입금 시점 사전 점검 — 오늘부터

오늘 6/4 ~ 6월 말 추천 일정:

| 날짜 | 액션 |
|------|------|
| **6/4 (오늘)** | 홈택스 환급금 조회 → 진행 단계 확인 |
| 6월 둘째 주 | 진행 단계 모니터링 |
| 6월 셋째 주 | \"승인\" 단계 진입 확인 |
| **6월 말** | **입금 대기** + 본인 계좌 잔액 모니터링 |
| 7월 초 | 입금 안 됐으면 진단 |
| 7월 중순 | 즉시 노란우산 추가 납입 결정 |

## 6월 말 입금된 직후 — 즉시 액션

환급 입금 확인 후 24시간 안:

1. **본인 한계세율 메모** (다음 절세 결정용)
2. **노란우산·연금저축 한도 확인** (미충족 여유 금액)
3. **이체 처리** — 한도 안 즉시 납입
4. **영수증 보관** — 내년 5월 신고 시 활용

오늘부터 6월 말까지 시뮬레이션 완료 → 7월 즉시 행동.

## 자주 발생하는 환급 추적 실수

자주 발생하는 실수:

- **\"자동 입금되겠지\" 무관심** → 계좌 오류 시 본인 정정 필요
- **\"7월에야 입금됨\" 오해** → 5/25 이전 신고자는 6월 말 가능
- **환급금 즉시 소비** → 절세 순환 기회 상실
- **본인 한계세율 모름** → 추가 납입 효과 추정 안 됨
- **노란우산 한도 미확인** → 더 넣을 여유 있는데 안 채움

가장 큰 손실 = \"환급금 = 공돈\" 인식 후 소비. 사실은 본인이 미리 낸 돈 + 재투입으로 더 큰 환급 가능.

## 환급 안 받는 케이스 — 자영업자 추가 납부자

환급 대상 아닌 자영업자:

- 분납 1차 5/31 처리 확인
- 2차 8/31 자동이체 설정 확인
- 7월 보험료 인상분 자금 준비

추가 납부 대상자도 노란우산 재투입은 유리 (다음 해 부담 감소).

## 결론: 6월 말 = 환급 입금 + 즉시 재투입 시점

종소세 환급 첫 입금은 절세 순환의 시작입니다. 정리:

- 5/25 이전 신고자 = 6월 말 ~ 7월 초 입금
- 6/4 오늘 = 진행 단계 추적 시작 시점
- 계좌 오류 사전 점검 + 정정 즉시
- 입금 직후 노란우산·연금저축 재투입
- 5년 누적 약 100~300만원 추가 절세 가능
