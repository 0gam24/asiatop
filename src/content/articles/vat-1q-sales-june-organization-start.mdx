7월 25일 부가세 1기 확정 신고 D-53. 1~6월 매출·매입 자료를 6월 안 정리하면 7월 마감 직전 부담이 1/10 수준으로 줄어듭니다. 종소세 매출과 일치 검증까지 사전 처리 권장.

### 핵심만 30초

- **부가세 1기 확정 신고**: 7월 25일 마감 (D-53)
- **신고 대상 기간**: 1~6월 매출·매입
- **6월 안 정리 권장**: 매출·매입 자료 자동 호출 + 본인 보관 자료
- **종소세 매출 일치**: 5월 신고와 합계 일치 필수
- **현금영수증 의무 발급**: 누락 시 20% 가산세

## 6월 안 정리할 매출 자료 — 5종

### 자동 호출 자료 (4종)
1. **전자세금계산서 발행분** — 홈택스 자동 호출
2. **신용카드 매출** — 카드사 정산 자료
3. **체크카드 매출** — 동일
4. **현금영수증 매출** — 본인 명의 발행분

### 본인 입력 자료 (1종)
5. **무통장 입금 매출** — 카드 외 매출, 본인 통장 내역으로 정리

자동 호출은 본인이 한 번 더 검증 필수. 카드사 시스템 지연·누락 가능.

## 6월 안 정리할 매입 자료 — 5종

매입세액 공제는 부가세 부담 줄이는 핵심:

| 자료 | 입증 형태 |
|------|----------|
| 임차료 | 세금계산서 또는 영수증 |
| 인건비 (외주 용역) | 세금계산서 또는 사업소득 원천징수 영수증 |
| 재료비 | 세금계산서 |
| 소모품·사무용품 | 신용카드 영수증 또는 현금영수증 |
| 통신비·전기·가스 (사업장 부분) | 청구서 또는 세금계산서 |

매입 자료가 충분히 갖춰지면 매출세액에서 매입세액 차감 → 실제 부가세 부담 크게 감소.

## 종소세 매출과 부가세 매출 일치 — 결정적

5월 종소세 신고 매출 + 1기 부가세 매출 + 2기 부가세 매출 = 연간 매출 = **일치 의무**.

| 종소세 (5/31) | 부가세 1기 (7/25) | 부가세 2기 (다음 해 1/25) |
|---------------|---------------------|----------------------------|
| 연간 매출 합계 | 1~6월 | 7~12월 |
| 일치 의무 ↓ | 1+2기 합계 = 연간 | 동일 |

불일치 시 국세청 자동 매칭 → 조사 대상.

**검증 방법**:
1. 5월 종소세 신고서 매출 합계 메모
2. 1~6월 부가세 매출 + 7~12월 부가세 매출 = 종소세 매출 일치 확인
3. 차이 발견 시 즉시 정정

## 6월 일별 정리 추천 일정

6월 한 달 동안 매주 1~2회 정리:

| 주 | 액션 |
|----|------|
| **1주차 (6/1~7)** | 1~3월 매출·매입 자료 정리 |
| 2주차 (6/8~14) | 4~5월 매출·매입 자료 정리 |
| 3주차 (6/15~21) | 카드사 정산 자료 검증 |
| 4주차 (6/22~28) | 종소세 매출 합계 일치 확인 |
| 5주차 (6/29~30) | 6월 매출 최종 정리 + 모의계산 |

월말까지 모든 정리 완료 → 7월 신고 시 단순 제출만.

## 현금영수증 의무 발급 — 누락 시 20% 가산세

의무 발급 업종 + 일정 금액 이상 거래:

| 업종 | 의무 발급 기준 |
|------|----------------|
| 학원 | 10만원+ |
| 미용 | 10만원+ |
| 변호사·세무사 | 10만원+ |
| 의원·치과 | 10만원+ |
| 골프장·헬스장 | 10만원+ |

누락 시 의무 발급액의 **20% 가산세** (부가가치세법). 매월 발급 의무 점검 필수.

## 부가세 분납 — 1천만원 초과

납부세액 1천만원 초과면 분납 가능:

| 납부세액 | 분납 |
|----------|------|
| 1천만 이하 | 일시 |
| 1천만 ~ 2천만 | 1차 1,000만 + 2차 잔액 |
| 2천만 초과 | 50% + 50% |

2차 납부 기한: 통상 9월 25일. 신고 시점에 분납 신청 체크.

## 7월 신고 직전 (7/20~25) 액션 — 5단계

6월 정리 끝났다면 7월은 단순 처리:

1. **홈택스 부가세 신고 메뉴** — \"세금신고 → 부가가치세 → 1기 확정 신고\"
2. **자동 호출 + 본인 보관 자료 대조**
3. **누락 항목 수동 입력**
4. **신고서 검토 + 분납 결정**
5. **제출 + 납부**

6월에 정리 끝났다면 7월 신고 30분~1시간 완료.

## 자주 발생하는 부가세 실수

자영업자 자주 발생하는 실수:

- **세금계산서 발행 누락** → 매출 누락 → 사후 적발 위험
- **카드 매출 자동 호출 신뢰** → 누락 확인 안 함
- **현금영수증 의무 발급 누락** → 20% 가산세
- **종소세 매출 vs 부가세 매출 불일치** → 조사 대상
- **간이영수증 매입 공제 시도** → 정식 세금계산서만 가능
- **개인 사용 비용 매입 처리** → 거부

\"세금계산서 발행 누락\" 이 가장 흔한 매출 누락 사례. 거래 시 즉시 발행 권장.

## 결론: 6월 정리 = 7월 마감 부담 1/10

부가세 7월 신고 부담은 6월 정리 여부가 결정합니다. 정리:

- 7/25 마감, 오늘 D-53
- 6월 안 매출·매입 자료 정리 → 7월 신고 30분 완료
- 종소세 매출과 부가세 매출 일치 의무
- 현금영수증 의무 발급 매월 점검
- 매입세액 공제 = 매월 영수증 보관이 핵심
- 1천만원 초과 분납 신청 가능
