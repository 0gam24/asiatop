만 0~5세 자녀 가정의 6월 결정: 어린이집 보육료 vs 가정 양육수당. 단순 금액은 보육료가 훨씬 크지만 부모 직접 양육과의 trade-off가 결정 핵심입니다. 본인 가정 상황별 결정 흐름을 정리합니다.

<div class="tldr">

### 핵심만 30초

- **어린이집 보육료**: 정부 약 30~50만 지원 + 본인 약 5~15만 부담
- **가정 양육수당**: 월 10~20만원 + 부모 직접 양육
- **시설 변경 즉시 신고 필수** (양육수당 ↔ 보육료 전환)
- **유치원** = 별도 \"유아학비\" 지원 (공립 10~30만, 사립 30~70만)
- **본인 가정 상황별 결정** = 단순 금액 비교 X

</div>

본 글의 지원 금액·자격은 보건복지부 운영 안내에 따라 변경될 수 있으니, 신청 전 [복지로](https://www.bokjiro.go.kr) 와 [아이사랑](https://www.childcare.go.kr) 공식 페이지를 재확인하시기 바랍니다. 본 글은 정보 제공 목적이며 법률 자문이 아닙니다.

## 두 제도 — 명확한 차이

자녀 보육 정부 지원 구조:

| 항목 | 어린이집 보육료 | 가정 양육수당 |
|------|-----------------|---------------|
| 대상 | 어린이집·유치원 등원 자녀 | 가정양육 자녀 |
| 정부 지원 | 월 약 30~50만원 | 월 10~20만원 |
| 본인부담 | 월 약 5~15만원 | 없음 |
| 부모 노동 | 어린이집 등원 시 부모 자유 | 부모 직접 양육 |
| 자녀 발달 | 또래 교류 + 보육사 | 부모 직접 양육 |
| **중복 수령** | **❌ X** | **❌ X** |

어린이집 다니면 양육수당 X. 가정양육이면 보육료 X.

## 어린이집 보육료 — 시간대별 차등

어린이집 보육료 지원 구조 (2026년 기준):

| 보육 형태 | 시간 | 정부 지원 | 본인부담 |
|-----------|------|-----------|----------|
| 종일반 | 07:30~19:30 | 약 30~50만 | 약 5~15만 |
| 반일반 | 09:00~13:00 | 약 15~25만 | 약 5~10만 |
| 야간 연장 | 19:30~22:00 | 별도 지원 | 추가 부담 |
| 24시간 보육 | 24시간 | 별도 지원 | 추가 부담 |

부모 맞벌이 시 종일반 + 야간 연장 활용.

## 본인부담금 — 가구 소득별

어린이집 본인부담금 (소득별 차등):

| 가구 소득 | 본인부담 (월) |
|-----------|----------------|
| 기초·차상위 | 0~3만원 |
| 중위 100% 이하 | 약 5만원 |
| 중위 150% 이하 | 약 10만원 |
| 중위 150% 초과 | 약 15만원+ |

저소득 가구 = 본인부담 거의 없음. 고소득 가구도 정부 지원 큼 → 본인부담 작음.

## 유치원 vs 어린이집 — 비교

만 3~5세 자녀의 두 선택:

| 시설 | 운영 시간 | 정부 지원 | 본인부담 (사립 기준) |
|------|-----------|-----------|------------------------|
| 어린이집 | 종일 (~19:30) | 보육료 | 5~15만 |
| 공립 유치원 | 보통 ~14:00 | 유아학비 | 거의 0 |
| 사립 유치원 | 보통 ~14:00 | 유아학비 | 약 10~30만 |

부모 맞벌이 = 어린이집 (종일) 유리. 일찍 귀가 + 학습 강화 = 유치원.

## 가정양육 → 어린이집 전환 — 6월 결정

어린이집 입소 결정 시 6월 액션:

1. **어린이집 검색** — [아이사랑](https://www.childcare.go.kr) 검색
2. **방문·상담** — 본인 가까운 어린이집 2~3곳
3. **입소 신청** — 대기자 등록 또는 직접 신청
4. **입소 결정** — 보통 1~2개월 대기
5. **양육수당 종료 + 보육료 신청** — 복지로 동시 처리

\"양육수당 → 보육료\" 전환은 즉시 신고 필수.

## 어린이집 → 가정양육 전환 — 즉시 처리

어린이집 퇴소 시:

1. **어린이집 퇴소 신청** — 어린이집 직접
2. **복지로 양육수당 신청** — 즉시 (자동 전환 X)
3. **첫 양육수당 입금** — 신청 익월 25일경

특히 \"양육수당 신청 누락\" = 월 10만 손실. 퇴소 동시 신청 권장.

## 본인 가정 상황별 결정 — 흐름

본인 가정 의사결정:

### 시나리오 1: 부모 맞벌이
→ **어린이집 보육료** (종일반 유리)

### 시나리오 2: 한쪽 부모 가정양육 + 자녀 발달 자극 원함
→ 어린이집 반일반 또는 가정양육 + 외부 활동

### 시나리오 3: 한쪽 부모 완전 양육
→ **가정 양육수당** (월 10~20만 + 부모 직접 양육)

### 시나리오 4: 만 3세+ 학습 강화
→ **공립 유치원** (저비용 + 학습)

본인 가정 노동 패턴 + 자녀 발달 단계 + 가구 소득에 따라 결정.

## 6월 신청 — 7월 적용 시점

6월 신청 시 적용 시점:

| 신청 | 시점 |
|------|------|
| 6월 초 신청 | 7월부터 적용 |
| 6월 말 신청 | 7~8월 적용 |
| 어린이집 대기 | 1~3개월 |

특히 인기 어린이집은 1년+ 대기. 미리 등록 권장.

## 보육료 신청 절차 — 5단계

복지로 신청:

1. **복지로 로그인** — [복지로](https://www.bokjiro.go.kr) 본인 인증
2. **보육료 메뉴** — \"복지서비스 → 보육료 신청\"
3. **어린이집 정보 입력** — 입소 어린이집 + 입소일
4. **자녀 정보 자동 호출** — 가족관계증명서 자동
5. **제출 + 본인 명의 계좌 등록**

신청 후 정부 지원 어린이집에 직접 지급. 본인은 본인부담금만 매월 어린이집에 납부.

## 자주 발생하는 결정 실수

자녀 보육 결정 시 자주 발생하는 실수:

- **\"보육료 무료\" 오해** → 본인부담금 5~15만 있음
- **\"부모급여 받고 어린이집 X\" 오해** → 만 0~23개월 부모급여 + 어린이집 일부 가능
- **\"양육수당 → 보육료 자동 전환\" 오해** → 본인 신청 필수
- **\"어린이집 즉시 입소 가능\" 오해** → 인기 어린이집 1년+ 대기
- **본인부담금 계산 안 함** → 가구 자금 부담 사전 점검 안 함

## 어린이집 운영 정보 — 자주 묻는 사항

- **운영 시간**: 종일반 07:30~19:30, 반일반 09:00~13:00
- **방학**: 통상 없음 (1년 운영)
- **공휴일**: 휴원
- **본인부담금 결제**: 매월 어린이집 직접
- **퇴소 통보**: 통상 1개월 전

## 결론: 본인 가정 상황 = 결정 핵심

어린이집 보육료 vs 가정 양육수당은 단순 금액이 아닌 가정 상황 결정입니다. 정리:

- 어린이집 = 부모 맞벌이 우선
- 가정양육 = 한쪽 부모 양육 + 월 10~20만
- 시설 변경 시 즉시 신고 (양육수당 vs 보육료 자동 전환 X)
- 본인 가구 소득별 본인부담 차등 (5~15만)
- 인기 어린이집 사전 등록 (1년+ 대기 가능)
