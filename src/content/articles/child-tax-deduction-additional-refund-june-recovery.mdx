1월 연말정산 시 자녀세액공제 누락한 직장인은 **6월 안 회복 가능**합니다. 자녀 1명당 25만~40만원 + 다자녀 추가 공제는 작지 않은 금액. 5월 신고 누락자도 6월 자진 신고로 같은 효과 + 가산세 감면 90%.

<div class="tldr">

### 핵심만 30초

- **자녀 1명** = 25만, **2명** = 55만, **3명+** = 1명당 40만 추가 (2025년 귀속 기준)
- **만 8세~20세** 자녀 (출생연도 기준)
- **5월 신고 또는 6월 자진 신고**로 회복
- **입금 시기**: 6~8월
- **다자녀 가구 회복 효과 큼** (3명+ 95만+)

## 자녀세액공제 — 정확한 금액

소득세법 제59조의2 기준 자녀세액공제 (2025년 귀속 — 2026년 5월 신고·6월 기한 후 신고분):

| 자녀 수 | 기본 공제 | 다자녀 추가 | 합계 |
|---------|-----------|--------------|------|
| 1명 | 25만 | - | 25만 |
| 2명 | 55만 (첫째 25만 + 둘째 30만) | - | 55만 |
| 3명 | 55만 | + 40만 | **95만** |
| 4명+ | 55만 | + 40만/명 | **135만+** |
| 출산·입양 (해당 연도) | + 30~70만 | - | + 30~70만 |

2025년 귀속분부터 첫째 25만·둘째 30만·셋째 이상 1명당 40만으로 상향됐습니다 (직전 2024년 귀속은 1명 15만·2명 35만·3명 65만). 다자녀 가구 = 회복 효과 매우 큼.

## 공제 대상 자녀 — 5가지 요건

자녀세액공제 자격:

| 요건 | 기준 |
|------|------|
| 본인·배우자 자녀 | ✅ |
| 입양·동거 자녀 | ✅ |
| 만 8세 ~ 20세 | 출생연도 기준 (2025년 귀속: 2005~2017년생) |
| 자녀 본인 소득 | 100만 이하 |
| 본인이 부양 | 함께 거주 또는 부양 사실 증명 |

자녀가 대학생 (만 18~20세) + 본인 소득 100만 이하 = 공제 가능.

## 연말정산 누락 사유 — 흔한 케이스

1월 연말정산 시 자녀공제 누락의 흔한 원인:

| 사유 | 발생 케이스 |
|------|--------------|
| 자녀 정보 미입력 | 시스템 자동 호출 안 됨 |
| 배우자가 동시 신청 | 중복 → 1명 거부 |
| 자녀 만 7세 → 만 8세 전환 모름 | 작년 만 7세, 올해 만 8세 |
| 새 자녀 출생 미신고 | 12월 출생 자녀 누락 |
| 시스템 오류 | 일부 케이스 |

특히 만 8세 자녀 = 처음 공제 대상. 본인 인식 부족으로 누락 잦음.

## 회복 방법 — 5월 종소세 신고 (1순위)

연말정산 누락 자녀공제 회복:

1. **[홈택스](https://www.hometax.go.kr) 종합소득세 신고 메뉴**
2. **"근로소득자 → 종합소득세 신고서 작성"**
3. **자녀 인적공제 추가 입력** — 자녀 주민번호
4. **자동 계산** — 자녀공제 금액 추가 환급액 표시
5. **신고 제출 + 본인 명의 계좌 확인**

5월 신고 시 처리 + 6월 말 추가 환급 입금.

## 5월 신고 누락 → 6월 자진 신고

5월 신고 누락한 직장인이 6월 자진 신고 시:

| 항목 | 결과 |
|------|------|
| 가산세 90% 감면 | 1개월 안 자진 |
| 자녀공제 회복 | 자동 적용 |
| 환급 입금 | 7~8월 |
| 추가 처벌 | 없음 |

특히 자녀공제는 자진 신고만으로도 자동 회복.

## 다자녀 가구 — 추가 환급 시뮬레이션

자녀 3명 가구 (1월 연말정산 시 자녀공제 누락):

| 시뮬레이션 | 금액 |
|-------------|------|
| 자녀 3명 기본 공제 (첫째 25만 + 둘째 30만) | 55만 |
| 다자녀 추가 공제 (셋째) | + 40만 |
| **합계 회복 가능** | **95만** |
| 4명+ 가구 | 135만+ |

다자녀 가구는 1차로 본인 자녀공제 적용 여부 점검 권장.

## 자녀공제 자동 호출 검증 — 사전 점검

[홈택스](https://www.hometax.go.kr) 본인 자녀 정보 자동 호출:

1. **홈택스 로그인 → 개인 → 가족관계 확인**
2. **자녀 정보 표시** — 주민번호 + 생년월일
3. **만 8세 이상 자녀 표시 여부** — 자동 호출 안 됨 시 누락 위험
4. **누락 발견 시 직접 입력**

자녀 출생 신고 정보가 홈택스로 자동 연결되지만 일부 케이스 누락.

## 자녀 본인 소득 100만 이하 — 검증

자녀 본인 소득이 100만 초과 시 공제 X:

| 자녀 소득 | 공제 가능 |
|-----------|-----------|
| 0 (학생) | ✅ |
| 알바 100만 이하 | ✅ |
| 알바 100만 초과 ~ 500만 | ❌ |
| 정기 근로 | ❌ |

특히 대학생 자녀 알바 본인 소득 사전 점검 필수.

## 출산·입양 자녀 추가 공제 — 보너스

해당 연도 출산·입양 자녀 추가 공제 (소득세법):

| 자녀 순위 | 추가 공제 |
|-----------|-----------|
| 첫째 출생·입양 | + 30만 |
| 둘째 출생·입양 | + 50만 |
| 셋째+ 출생·입양 | + 70만 |

2025년 출생·입양 자녀 = 추가 공제. 1월 연말정산 누락 시 5~6월 회복.

## 추가 환급 입금 시기 — 실제 흐름

자녀공제 회복 신청 후 입금:

| 신청 시점 | 추가 환급 입금 |
|-----------|------------------|
| 5월 신고 (정상) | 6월 말 ~ 7월 초 |
| 5월 말 ~ 6월 초 신고 | 7월 중·말 |
| 6월 중·말 자진 신고 | 8월 |
| 7월 자진 신고 | 8월 말 ~ 9월 |

빨리 신고 = 입금 빠름.

## 본인 명의 계좌 확인 — 입금 차단 회피

추가 환급 입금 확인:

| 점검 | 확인 |
|------|------|
| 본인 명의 계좌 | 통장 명의 |
| 활성 계좌 | 은행 앱 |
| 원화 계좌 | 외화 X |

계좌 오류 시 환급 반송 → 정정 신청 필수. 자세히는 머니룩의 [환급 미입금 진단](/tax/comprehensive-income-tax-refund-not-deposited-diagnosis/) 가이드 참고.

## 자주 발생하는 자녀공제 실수

자주 발생하는 실수:

- **"연말정산 = 끝" 오해** → 종소세 신고로 회복 가능 모름
- **자녀 만 8세 전환 누락** → 첫 공제 대상 모름
- **자녀 본인 소득 100만 초과** → 공제 X 인식 못함
- **배우자와 중복 신청** → 한 명 거부
- **다자녀 추가 공제 미적용** → 3명+ 95만+ 누락

가장 흔한 = "연말정산 끝" 오해. 6월 안 회복 가능.

## 자녀공제 vs 자녀장려금 — 다른 제도

자녀공제와 별개 제도:

| 제도 | 대상 | 신청 시기 |
|------|------|-----------|
| 자녀세액공제 | 만 8~20세 자녀 부양 | 1월 또는 5월 |
| 자녀장려금 | 만 18세 미만 자녀 + 소득 기준 | 5월 |
| 자녀양육비 비과세 | 만 6세 이하 자녀 | 월급여 |

세 제도 모두 별개. 중복 수령 가능.

## 결론: 다자녀 가구 = 회복 효과 큼

자녀세액공제는 다자녀 가구일수록 회복 효과가 큽니다. 정리:

- 1월 연말정산 시 누락한 자녀공제는 6월 안 회복 가능
- 자녀 1명 = 25만, 2명 = 55만, 3명+ = 95만+ (2025년 귀속 기준)
- 출산·입양 자녀 추가 30~70만
- 5월 신고 또는 6월 자진 신고
- 입금 시기 = 6~8월
