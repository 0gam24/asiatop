만 65세+ 부모 부양 가구는 6월 노인장기요양보험 점검 + 가족요양보호사 활용으로 큰 절약 가능합니다. 부모 등급, 재가/시설 결정, 가족 수입 가능성까지 종합 정리.

<div class="tldr">

### 핵심만 30초

- **만 65세+ 또는 노인성질환** = 등급 신청 가능
- **본인부담**: 재가 15%, 시설 20% (기초·차상위 0~8%)
- **가족요양보호사** = 월 50~80만 수입 가능
- **6월 등급 재신청** = 부모 악화 시 유리
- **7월 건보료 정기조정** = 본인 장기요양보험료 포함

</div>

본 글의 등급·자격은 보건복지부·건보공단 운영 안내에 따라 변경될 수 있으니, 신청 전 [국민건강보험공단](https://www.nhis.or.kr) 와 [복지로](https://www.bokjiro.go.kr) 공식 페이지를 재확인하시기 바랍니다. 본 글은 정보 제공 목적이며 의료 자문이 아닙니다.

## 장기요양 등급 — 1~5등급 + 인지지원 등급

장기요양보험 등급 (노인장기요양보험법):

| 등급 | 일상생활 능력 | 월 한도 (대략) |
|------|----------------|------------------|
| 1등급 | 일상생활 전적 도움 | 약 220만 |
| 2등급 | 일상생활 상당 부분 도움 | 약 195만 |
| 3등급 | 일상생활 부분 도움 | 약 165만 |
| 4등급 | 일상생활 일정 부분 도움 | 약 140만 |
| 5등급 | 치매 (경증) | 약 125만 |
| 인지지원 등급 | 치매 (경도) | 약 75만 |

등급 높을수록 = 한도 큼 + 본인부담 비율 같음.

## 등급 신청 절차 — 5단계

부모 등급 신청:

1. **건강보험공단 지사** 방문 또는 [건보공단](https://www.nhis.or.kr) 홈페이지
2. **장기요양인정 신청서** 작성
3. **현장 조사** — 본인 거주지 방문 (15~30일)
4. **의사 소견서** 제출
5. **등급판정위원회 심사 + 등급 결정** (약 1개월)

신청 후 약 1개월. 등급 결정 후 즉시 서비스 이용 가능.

## 본인부담 — 가구 소득별 차등

본인부담 비율 (가구 소득 기준):

| 가구 소득 | 재가급여 | 시설급여 |
|-----------|----------|----------|
| 기초생활수급자 | 0% | 0% |
| 차상위 | 6% | 8% |
| 중위 50% 이하 | 9% | 12% |
| 일반 가구 | **15%** | **20%** |

저소득 가구 = 본인부담 거의 없음.

## 재가급여 vs 시설급여 — 결정 기준

재가급여 vs 시설급여:

| 항목 | 재가급여 | 시설급여 |
|------|----------|----------|
| 부모 거주 | 집 | 요양원·요양병원 |
| 본인부담 | 15% | 20% |
| 가족 부담 | 일부 (집안 환경 조성) | 적음 |
| 월 한도 | 1~5등급별 | 1~5등급별 |
| 적합 케이스 | 부모 본인 집 거주 원함 | 가족이 부양 어려움 |

재가급여 = 본인부담 작고 부모 집 거주. 시설급여 = 본인부담 크지만 가족 부담 작음.

## 재가급여 종류 — 6가지

재가급여 서비스 종류:

| 서비스 | 내용 |
|--------|------|
| 방문요양 | 요양보호사 본인 집 방문 |
| 방문목욕 | 이동식 목욕 서비스 |
| 방문간호 | 간호사 방문 |
| 주야간보호 | 낮 시간 보호 (어린이집 형태) |
| 단기보호 | 1~30일 시설 입소 |
| 복지용구 | 보행기·휠체어 등 |

가족 상황별 조합 활용 가능.

## 가족요양보호사 — 가구 활용

가족 (배우자·자녀)이 요양보호사 자격 취득 후 부모 돌봄 가능:

| 항목 | 결과 |
|------|------|
| 자격 취득 | 약 240시간 교육 + 시험 |
| 자격증 발급 | 약 2~3개월 |
| 가족 돌봄 시 정부 지원 | 월 약 50~80만 |
| 본인 자유로움 | 부모 옆 거주 가능 |

특히 자녀가 부모 부양 가구 = 가족요양보호사 활용 권장.

## 가족요양보호사 시뮬레이션

자녀가 부모 (3등급) 가족요양 시:

| 항목 | 금액 |
|------|------|
| 정부 지원 (가족요양보호사) | 약 50~80만/월 |
| 부모 본인부담 (15%) | 약 25만/월 |
| 자녀 노동 시간 | 약 90시간/월 |
| 시간당 수입 | 약 6,000~9,000원 |

자녀가 직장 다니지 않거나 부분 일하는 케이스에 적합.

## 6월 점검 — 5가지

부모 부양 가구 6월 점검:

| 점검 | 액션 |
|------|------|
| 부모 등급 유효성 | 등급 재인증 필요 시 |
| 부모 상태 악화 → 등급 재신청 | 1단계 ↑ 가능 |
| 가족요양보호사 자격 검토 | 자녀 가능 시 |
| 본인부담 최적 (재가 vs 시설) | 가구 상황 |
| 7월 건보료 정기조정 영향 | 본인 장기요양보험료 |

6월 점검 = 7월 정기조정 사전 대응 + 부모 케어 최적화.

## 7월 건보료 정기조정 — 장기요양보험료 포함

본인 (자녀) 건보료 + 장기요양보험료:

| 항목 | 비율 |
|------|------|
| 건강보험료 | 보수월액 × 7.09% |
| **장기요양보험료** | 건강보험료 × 약 12.95% |
| 합계 | 약 7.5~8% |

작년 보수 ↑ = 7월 건보료 + 장기요양보험료 ↑.

## 본인 부담 시뮬레이션 — 가구별

부양자 (자녀) + 부모 부양 시 본인부담 시뮬레이션:

| 부모 등급 | 가구 소득 | 본인부담 (월) |
|------------|-----------|----------------|
| 3등급 + 재가 | 일반 가구 | 약 25만 |
| 3등급 + 시설 | 일반 가구 | 약 33만 |
| 3등급 + 재가 | 차상위 | 약 10만 |
| 1등급 + 재가 | 일반 가구 | 약 33만 |
| 1등급 + 시설 | 일반 가구 | 약 44만 |

가구 소득별 차등 적용. 차상위 자격 점검 권장.

## 등급 재신청 — 부모 상태 악화 시

부모 상태 악화 = 등급 재신청 권장:

| 신호 | 등급 재신청 필요 |
|------|---------------------|
| 일상생활 도움 ↑ | 4 → 3등급 가능 |
| 치매 진행 | 5등급 → 1~4등급 가능 |
| 거동 불가 | 1등급 가능 |
| 본인 의사 표현 어려움 | 1등급 가능 |

등급 ↑ = 월 한도 ↑ + 가족 부담 ↓.

## 부모 부양 + 본인 종합소득세 — 인적공제

부모 부양 시 본인 종합소득세 인적공제:

| 항목 | 공제액 |
|------|--------|
| 기본공제 (1인 부양) | 150만 |
| 경로우대 (만 70+) | + 100만 |
| 장애인 공제 | + 200만 |
| 의료비 | 본인 합산 |

부모 부양 신고 = 본인 종합소득세 절감 + 장기요양 활용 동시 가능.

## 자주 발생하는 6월 점검 실수

자주 발생하는 실수:

- **"등급 신청 = 어렵다" 오해** → 본인 신청 가능 (대리인 불필요)
- **부모 악화 후에도 등급 재신청 안 함** → 한도 부족
- **가족요양보호사 모름** → 가구 수입 기회 손실
- **시설급여만 검토** → 재가급여 본인부담 작음 모름
- **본인 건보료에 장기요양보험료 포함 무인식** → 7월 정기조정 모름

가장 흔한 = 등급 재신청 안 함. 1년 1회 점검 권장.

## 결론: 가족요양보호사 + 등급 점검 = 가구 부담 ↓

노인장기요양보험은 부모 부양 가구의 큰 절약 도구입니다. 정리:

- 만 65+ 부모 또는 노인성질환 = 등급 신청 가능
- 본인부담 재가 15%, 시설 20%
- 가족요양보호사 = 월 50~80만 가구 수입
- 6월 등급 재신청 검토 + 7월 건보료 정기조정 사전 대비
- 자녀 인적공제 + 의료비 합산 활용
