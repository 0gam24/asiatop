5월 종합소득세 환급금 6월 말 첫 입금 시점입니다. 5/25 이전 신고자 중 환급금 미입금 발생 시 즉시 진단 + 정정 신청이 정공. 7월 환급 입금 일정 보호를 위해 본인이 직접 확인해야 합니다.

<div class="tldr">

### 핵심만 30초

- **미입금 발견 시점**: 6월 말 ~ 7월 초
- **사유 1순위**: **계좌 오타** (80%+)
- **진단 메뉴**: [홈택스](https://www.hometax.go.kr) \"환급금 조회\"
- **정정 절차**: \"환급 계좌 정정 신청\" 메뉴 4단계
- **재처리**: 정정 후 2~4주 추가

</div>

본 글의 절차·시점은 국세청·국세기본법 운영 안내에 따라 변경될 수 있으니, 처리 전 [홈택스](https://www.hometax.go.kr) 와 [국세청](https://www.nts.go.kr) 공식 페이지를 재확인하시기 바랍니다. 본 글은 정보 제공 목적이며 세무 자문이 아닙니다.

## 1단계: 홈택스 환급금 조회 — 현재 단계 확인

진행 단계별 의미:

| 단계 | 상태 | 다음 액션 |
|------|------|-----------|
| 접수 | 신고서 접수 | 정상, 대기 |
| 심사 중 | 환급 적정성 검토 | 정상, 대기 (2~4주) |
| **승인** | **환급액 확정** | 입금 임박 |
| **입금** | **계좌 입금 완료** | 본인 계좌 잔액 확인 |

\"입금\" 표시 후 7일+ 지나도 본인 계좌에 안 들어오면 = 계좌 오류 가능성 매우 큼.

## 미입금 사유 — 5가지 진단

### 1. 계좌 오타 (가장 흔함, 80%+)
- 신고서 작성 시 계좌번호 1자리 틀림
- 은행 시스템 입금 거부 → 국세청 반송
- **진단**: 신고서 계좌 vs 본인 통장 계좌 1자리씩 대조

### 2. 폐쇄 계좌
- 작년 신고 시 자동 호출 계좌가 폐쇄 또는 휴면 처리
- 본인이 모르고 그대로 입력
- **진단**: 은행 앱에서 본인 계좌 활성 상태 확인

### 3. 가족 명의 계좌
- 본인 인식 부족으로 배우자·자녀 계좌 입력
- 본인 명의 외 거부
- **진단**: 통장 명의 확인

### 4. 외화 계좌
- USD·EUR 등 외화 계좌 입력
- 원화 계좌만 가능
- **진단**: 계좌 종류 확인 (원화 보통예금 권장)

### 5. 동결 계좌
- 신용·세금·법적 사유로 본인 계좌 동결
- 입금 자체 차단
- **진단**: 은행에 동결 여부 문의

## 정정 신청 — 4단계

위 5가지 사유 발견 시 즉시:

1. **홈택스 로그인** — [홈택스](https://www.hometax.go.kr)
2. **세금신고 → 환급 계좌 정정 신청** 메뉴 진입
3. **본인 명의 활성 원화 계좌 재입력** — 통장 확인 후
4. **제출 + 처리 대기** — 통상 2~4주 추가 처리

빨리 정정 = 입금 빠름.

## 재처리 시점 — 정정 후

정정 신청 후 환급 일정:

| 정정 시점 | 재처리 입금 |
|-----------|------------|
| 6월 첫 주 정정 | 6월 말 ~ 7월 초 |
| 6월 중·말 정정 | 7월 중순 |
| 7월 정정 | 7월 말 ~ 8월 |
| 8월 정정 | 8월 말 ~ 9월 |

빨리 정정할수록 입금 빠름. 오늘(6/5) 정정 시 6월 말 재입금 가능.

## 본인 계좌 확인 — 사전 점검

정정 신청 전 본인 계좌 점검:

| 점검 항목 | 확인 방법 |
|-----------|-----------|
| 본인 명의 | 통장 또는 은행 앱 |
| 활성 상태 | 은행 앱 로그인 가능 |
| 원화 계좌 | 외화 X |
| 동결 X | 은행 문의 |
| 잔액 조회 가능 | 거래 가능 |

5개 모두 \"YES\" 인 계좌 = 안전. 새 계좌 사용 권장.

## 7월 말까지 미입금 — 즉시 액션

7월 말까지 입금 없으면 즉시:

1. **홈택스 환급금 조회** — 어느 단계에서 멈췄는지 재확인
2. **계좌 정확성 재확인** — 본인 명의·활성·원화
3. **국세청 콜센터 (126)** — 진행 상황 문의
4. **세무서 방문** — 필요 시
5. **정정 신청** — 계좌 문제면 즉시

## 정정 신청 시 자주 발생하는 실수

자주 발생하는 정정 실수:

- **\"환급금 자동 입금\" 무관심** → 본인 정정 안 함 → 6개월 후에야 발견
- **다시 같은 잘못된 계좌 입력** → 또 거부
- **외화 계좌 알고도 입력** → 또 거부
- **CMA·증권사 계좌 입력** → 일부 거부
- **국세청에서 자동 정정 기대** → 본인 신청 안 하면 X

가장 흔한 \"자동 입금\" 오해. 본인이 정정 신청 안 하면 환급금은 국세청 미수령 상태로 남음.

## 환급금 미수령 — 5년 룰

환급금이 본인 계좌 입금 안 된 상태로 5년 경과 시:

- 환급금 청구권 소멸
- 영구 손실
- 사후 청구 불가

따라서 빨리 정정·신청 권장. 6월 입금 안 됐다면 즉시 진단.

## 정정 후 — 다음 환급 시점 보호

정정 신청 후 다음 환급 (내년 5월) 위한 사전 점검:

- 본인 명의 활성 계좌 유지
- 계좌 변경 시 미리 홈택스 등록
- 매년 5월 신고 시 자동 호출 계좌 검증

\"본인 통장 = 종소세 환급 계좌\" 안정 유지 권장.

## 미입금 진단 — 빠른 자가 체크

다음 3가지 확인:

- [ ] 홈택스 환급금 조회에 본인 신고 표시되나? (없으면 신고 누락)
- [ ] 단계가 \"입금\" 인데 본인 계좌 입금 안 됐나? (계좌 오류 1순위)
- [ ] 단계가 \"심사 중\" 이면? (정상, 대기)

3개 결과에 따라 다음 액션 결정.

## 신고 자체 누락 케이스 — 즉시 재신고

홈택스에 본인 신고 표시 없으면:

- 신고 자체가 안 됐을 가능성
- 6월 즉시 자진 신고 (가산세 90% 감면)
- 환급 검토 시작 → 7~8월 입금 가능

자세히는 머니룩의 [기한 후 신고 6/1 즉시 처리](/tax/comprehensive-income-tax-late-filing-june-1/) 가이드 참고.

## 결론: 미입금 발견 = 즉시 진단 + 정정

종소세 환급 미입금은 본인이 즉시 대응해야 회복 가능합니다. 정리:

- 미입금 발견 시 홈택스 \"환급금 조회\" 단계 확인
- 5가지 사유 (계좌 오타·폐쇄·가족 명의·외화·동결)
- 즉시 \"환급 계좌 정정\" 신청 4단계
- 정정 후 2~4주 재처리
- 5년 미수령 시 영구 손실
