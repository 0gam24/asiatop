### 핵심만 30초

- **이사 후 14일 이내** — 미신고 시 5만원 과태료.
- **정부24 모바일 5분** — 본인인증 + 새 주소 입력 → 자동 처리.
- **세대주 동의 필요** — 새 거주지 세대주(또는 임대인) PASS 인증 동의.
- **확정일자 동시** — 임대차 신고 + 전입신고 동시 처리 가능.
- **전기·도시가스 자동 통보** — 전입신고로 공과금 명의 변경 자동.

</div>

## 전입신고, 정확히 뭔가요?

전입신고는 **새 주소지에 본인 거주지를 등록하는 행정 절차**입니다([행정안전부](https://www.mois.go.kr) 주민등록법 제16조).

이사 후 14일 이내 신고 의무. 전입신고 효력:
- 주민등록상 거주지 변경
- **임차인 대항력 발생**
- 운전면허증 주소 자동 변경
- 전기·수도·도시가스 명의 자동 통보 (일부 지자체)

## 14일 이내 안 하면 어떻게 되나요?

5만원 과태료 부과 가능(주민등록법 제40조).

| 미신고 기간 | 과태료 |
|---|---|
| 정당한 사유 없는 미신고 | 최대 5만원 |
| 거짓 신고 | 100만원 이하 |
| 부정 사용 (타인 명의 등) | 형사처벌 (3년 이하 징역) |

실제 5만원 부과 사례는 적지만 늦으면 큰 피해 발생 (확정일자 지연 → 보증금 보호 약화).

## 정부24 모바일 신고 절차

[정부24](https://www.gov.kr) 앱 또는 웹에서 5분 완료.

1. 정부24 로그인 (공동인증서·간편인증)
2. "민원서비스" → "전입신고"
3. 신청자 정보 입력 (자동 채워짐)
4. 새 주소 + 거주지 정보 입력
5. **세대주 동의 절차** (PASS 또는 공동인증서)
6. 임대차 신고 동시 진행 여부 선택 (권장)
7. 제출 → 즉시 접수 + 처리

처리: 보통 즉시 ~ 1영업일 내 완료.

## 세대주 동의, 어떻게 받나요?

새 거주지에 기존 세대주(또는 임대인)이 있으면 동의 필요.

| 케이스 | 동의자 |
|---|---|
| 신규 단독 세대 | 본인 단독 (동의 불요) |
| 기존 가족 세대 합류 | 기존 세대주 |
| 임차 (임대인이 세대주 X) | 임대인 |
| 임차 + 임대인 비거주 | 임대인 동의 (PASS·공동인증서) |

동의 방법:
- PASS 인증 (가장 빠름, 5초)
- 공동인증서 (1분)
- 거부 또는 응답 없음 → 주민센터 방문 처리

## 확정일자 동시 처리, 어떻게 하나요?

전월세 신고제 도입(2021년) 이후 **전입신고 + 임대차 신고 + 확정일자 동시 처리** 가능.

절차:
1. 전입신고 메뉴에서 "임대차 신고 함께" 선택
2. 임대차계약서 사진/PDF 업로드
3. 보증금·월세 입력
4. 제출 → 전입 + 임대차 + 확정일자 일괄 처리

확정일자는 **임차인 우선변제권**의 핵심. 보증금 보호를 위해 반드시 받아야 함.

## 14일 지났으면 어떻게 하나요?

지금이라도 즉시 신고 권장. 절차는 동일하지만 과태료 부과 가능성 있음.

자진 신고 시:
- 5만원 미만 부과 흔함
- 일부 사정 (군복무·해외 거주) 시 면제 가능
- 미신고 기간 길수록 과태료 ↑

미신고 → 발각 → 부과 흐름이라 즉시 처리가 정답.

## 가족과 함께 이사, 가족 신고는 어떻게?

본인이 신청 시 **가족 동시 처리 가능**:

1. 본인 인증 후 전입신고 메뉴 진입
2. "이사 가족 추가"
3. 가족 주민번호 입력
4. **가족 본인 동의** (PASS 또는 공동인증서)
5. 일괄 신청

가족마다 별도 신청 불요 — 한 번에 처리.

## 전입신고 후 자동으로 변경되는 것

전입신고 완료 시 자동 변경되는 항목:

- 주민등록증 주소 (재발급 불요, 등본만 새 주소)
- **운전면허증 주소** (자동 통보)
- 자동차 등록 주소 (자동 통보)
- 일부 지자체 전기·도시가스 명의
- 학교 학적 (자녀, 일부)

수동 변경 필요한 항목:
- 은행·카드 회원 정보
- 의료보험 (대부분 자동, 일부 수동)
- 통신사 서비스 주소

## 단순 거주지 변경 vs 세대 분리 차이

| 구분 | 효과 |
|---|---|
| 거주지 변경 | 같은 세대 그대로, 주소만 변경 |
| **세대 분리** | 새 세대 신설, 본인 세대주 |
| 세대 합류 | 기존 다른 세대로 합류 |

세대 분리 = 독립 세대주가 됨 → 1인 세대로 간주 (청년 정책 등에서 유리). 정부24에서 별도 처리.

## 확정일자 받아야 하는 임차 케이스

다음 경우 확정일자 필수:

- 보증금 1천만원 이상
- 전세 (보증금 큼)
- 반전세 (보증금 + 월세)
- 직접 임차

확정일자 없으면 경매·공매 시 보증금 후순위로 밀림 → 회수 어려움.

## 전입신고 거부될 때 사유

이런 경우 전입 신고 반려 가능:

1. 세대주 동의 거부
2. 임대인 거부 (임대 사실 부인)
3. 주소 정확성 부족 (건물 미등록 등)
4. 가짜 거주 의심

해결:
- 거부 사유 통보 받음
- 주민센터 방문 → 임대차계약서·실거주 증빙 제출
- 분쟁 시 [법률구조공단](https://www.klac.or.kr) 무료 상담

## 외국인 전입신고는?

외국인은 별도 절차:

- **국내거소신고**: 출입국·외국인청 ([hikorea.go.kr](https://www.hikorea.go.kr))
- 한국인 가족과 동거 시: 가족이 정부24 가구원 추가

외국인등록증 보유자는 90일 내 거소 변경 신고 의무.

## 자주 발생하는 실수

1. **세대주 동의 미완료**: 임대인이 PASS 인증 안 함 → 5일 내 미응답 시 신고 자동 반려
2. **임대차 신고 누락**: 전입신고만 하고 임대차 신고 별도로 안 함 → 30일 내 추가 신고 필요
3. **확정일자 누락**: 임대차 신고 시 자동 부여, 별도 안 받으면 손해
4. **주소 표기 오류**: 신축 건물·복합 호수 정확 표기 필요

---

전입신고는 이사 당일 또는 다음 날 즉시 처리가 정답. 정부24에서 5분이면 끝나고, 임대차 신고 + 확정일자까지 한 번에 처리하면 보증금 보호도 동시에 완료. 14일 지나면 과태료 가능성 있으니 미루지 마세요.
