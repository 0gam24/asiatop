5월 종소세 마감 끝났으니 \"이제 1년 쉴 수 있다\" 가 가장 위험한 안일함입니다. 사업소득자의 진짜 절세는 **6월부터 시작하는 12개월 누적 시스템**에서 나옵니다. 6월 시작하면 내년 5월 환급액을 30~50% 키울 수 있습니다.

<div class="tldr">

### 핵심만 30초

- **5월 종소세 마감 끝 = 다음 해 신고의 시작**
- **3대 시스템**: 사업 전용 계좌 / 영수증 자동 수집 / 노란우산·연금저축 정기 납입
- **6월 시작**: 12개월 누적 효과 최대
- **내년 환급액**: 시스템 구축 자영업자 vs 미구축 = **30~50% 차이**
- **누락 위험 감소**: 매월 정리 vs 5월 일괄 정리 = 누락률 1/5

## 6월부터 시작하는 3대 시스템

### 1. 사업 전용 계좌 분리

가장 단순한데 효과 가장 큰 시스템:

| 분리 전 | 분리 후 |
|---------|---------|
| 개인+사업 자금 혼재 | 명확히 구분 |
| 5월에 1년치 정리 → 8시간 | 자동 합산 → 30분 |
| 누락·중복 자주 | 누락 거의 없음 |
| 세무 조사 위험 ↑ | 위험 감소 |

**6월에 처리**:
1. 은행에서 사업자 명의 별도 계좌 개설 (10분)
2. 매출 입금 통로를 사업 계좌로 변경 (카드사·플랫폼 등)
3. 사업 경비는 사업 카드만 사용
4. 개인 자금 입출금은 별도 계좌

### 2. 영수증 자동 수집 시스템

매월 1~2시간 정리:

- **신용카드·체크카드 명세 자동 다운로드** — 카드사 앱에서 월별 PDF
- **모바일 영수증 앱** — 종이 영수증 즉시 촬영·보관
- **세금계산서 자동 알림** — 거래처에 전자세금계산서 발행 요청
- **현금영수증** — 본인 명의 자동 합산 (홈택스에서 조회)

**6월부터 매월 마지막 날** 1~2시간 정리 → 5월 신고 부담 1/10 수준.

### 3. 노란우산·연금저축 정기 납입

매월 자동이체로 누적:

- **노란우산공제**: 매월 일정액 자동 납입 (한도 내 본인 결정)
- **연금저축**: 동일하게 자동이체
- **IRP**: 동일

**효과**:
- 12개월 누적 → 본인 한도까지 채움
- 매년 환급액 확정 → 자금 계획 예측 가능
- 노후 자금 + 절세 + 압류 보호

## 매월 마지막 날 1~2시간 정리

추천 월간 정리 체크리스트:

| 항목 | 소요 시간 |
|------|-----------|
| 카드 매출·매입 정리 | 30분 |
| 세금계산서 발행/수령 점검 | 20분 |
| 현금영수증 자동 합산 확인 | 10분 |
| 영수증 (사업 전용 카드 외 결제) 정리 | 20분 |
| 노란우산·연금저축 납입 확인 | 10분 |

월 1.5시간 × 12개월 = 18시간. 5월에 일괄 정리하면 40~60시간 → **약 50% 시간 절약** + 누락 감소.

## 단순경비율 vs 기준경비율 — 사전 점검

올해 매출이 단순경비율 한도 초과 가능성 점검:

| 업종 | 단순경비율 한도 |
|------|-----------------|
| 서비스업 | 약 2,400만원 |
| 제조·건설업 | 약 3,600만원 |
| 도소매업 | 약 6,000만원 |

**올해 매출 한도 직전이라면**:
- 6월부터 영수증 보관 강화 (기준경비율 또는 장부 전환 대비)
- 간편장부 또는 복식부기 사전 학습
- 세무대리인 사전 상담

내년 5월에 갑작스러운 전환 부담 회피.

## 매출 증가 자영업자 — 7월 보험료 인상 대비

올해 매출 큰 폭 증가했으면 내년 7월 보험료 인상 폭증 예상:

| 매출 증가율 | 내년 7월 보험료 변동 |
|--------------|----------------------|
| +20% | +15~20% |
| +50% | +35~45% |
| +100% | +60~80% |

**6월부터 대비**:
1. 매월 자금 적립 → 7월 인상분 비축
2. 분납 신청 사전 계획
3. 매출 증가 추세 시 절세 도구 한도 채우기 (노란우산 등)

## 부가세 2기 사전 준비 — 7~12월 매출

부가세 2기 확정 신고 (다음 해 1/25) 사전 준비도 6월부터:

| 시점 | 액션 |
|------|------|
| 6월 ~ 12월 | 매월 매출·매입 자료 정리 |
| 10월 (법인) | 부가세 2기 예정 신고 |
| 12월 말 | 2기 매출·매입 합계 점검 |
| 1/25 | 2기 확정 신고 마감 |

매월 정리 시스템 구축하면 7월 1기 + 1월 2기 모두 부담 감소.

## 자주 발생하는 6~12월 실수

자영업자가 자주 빠뜨리는 것:

- **\"5월 끝났으니 1년 쉰다\"** → 다음 해 5월 폭주
- **사업 전용 계좌 안 만듦** → 정리 시간 폭증
- **영수증 안 보관** → 기준경비율·간편장부 시 손해
- **노란우산·연금저축 1월 일시납만** → 자동이체 안 함 → 누락 자주
- **세무대리인 의뢰 시점 늦음** → 5월 막판 의뢰 거절 + 추가 수임료

가장 큰 실수가 \"매월 정리 안 함\". 1년 누적 5월 일괄 정리 = 누락 폭증 + 시간 8배.

## 6월 첫 주 추천 액션

6월 1일~7일 추천 일정:

| 날짜 | 액션 |
|------|------|
| 6/1 (월) | 종소세 신고 처리 상태 확인 + 환급 추적 |
| 6/2 (화) | 사업 전용 계좌 개설 (은행 방문 또는 온라인) |
| 6/3 (수) | 카드 매출·매입 통로 사업 계좌로 변경 |
| 6/4 (목) | 모바일 영수증 앱 설치·세팅 |
| 6/5 (금) | 노란우산·연금저축 자동이체 설정 |
| 6월 ~ | 매월 마지막 날 1~2시간 정리 시작 |

6월 첫 주에 시스템 구축 → 12개월 누적 → 내년 5월 환급 극대화.

## 시스템 구축 후 5월 신고 비교

12개월 시스템 구축 자영업자 vs 미구축 자영업자 차이:

| 항목 | 시스템 미구축 | 시스템 구축 |
|------|---------------|-----------|
| 5월 신고 준비 시간 | 30~50시간 | 5~10시간 |
| 영수증 누락률 | 약 30% | 약 5% |
| 매출 누락 위험 | 중간 | 낮음 |
| 노란우산 한도 활용 | 60% | 100% |
| 환급액 (동일 매출 기준) | 100만원 | 130~150만원 |

= 시스템 구축으로 **시간 80% 단축 + 환급 30~50% 증가**.

## 세무대리인 의뢰 자영업자도 시스템 필요

세무대리인 의뢰해도 자영업자가 시스템 구축하면 이득:

- **수임료 감소** — 자료 정리 시간 짧음 → 세무사 시간 절약
- **누락 감소** — 본인이 한 번 더 체크
- **정확도 ↑** — 본인·세무사 양쪽 검증
- **세무 조사 대비** — 자료 보관 잘 됨

## 결론: 6월 = 다음 해 절세의 시작점

종소세 마감은 끝이 아니라 다음 해 절세의 시작입니다. 핵심 정리:

- 6월부터 12개월 시스템 누적 = 내년 환급 30~50% 증가
- 사업 전용 계좌 + 영수증 자동 수집 + 노란우산·연금저축 자동이체 3대 시스템
- 매월 1~2시간 정리 = 5월 부담 1/10
- 매출 증가 자영업자는 단순경비율 한도 사전 점검
- 시스템 구축은 세무대리인 의뢰자에게도 이득
