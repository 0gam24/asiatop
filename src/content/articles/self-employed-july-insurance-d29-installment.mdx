5월 종합소득세 신고 매출이 7월 중순부터 건강보험·국민연금 보험료에 자동 반영됩니다. 오늘 6/4 기준 D-29. 미리 자금 시뮬레이션 + 분납 신청 사전 준비하면 7월 자금 충격 회피 가능합니다.

### 핵심만 30초

- **7월 보험료 통보**: **7월 중순** (오늘 D-29)
- **매출 50% 증가** = 보험료 35~45% 인상
- **매출 50% 감소** = 자동 인하 (별도 신청 X)
- **분납 신청**: 통보서 받은 후 즉시, 최대 10회
- **6월부터 자금 시뮬레이션 권장**

## 7월 보험료 변동 시뮬레이션 — 매출별

5월 종소세 신고 매출에 따른 7월 보험료 변동 (월 기준):

| 매출 증감 | 건강보험료 변동 | 국민연금 변동 | 합계 부담 |
|------------|------------------|----------------|-----------|
| +100% | +60~80% | +50~80% | 매우 큼 |
| +50% | +35~45% | +30~50% | 큼 |
| +20% | +15~20% | +15~20% | 중간 |
| 동결 | 변동 X | 변동 X | 없음 |
| -20% | -15~20% | -15~20% | 인하 |
| -50% | -40~50% | -40~50% | 큰 폭 인하 |

매출 1억 자영업자 (현재 월 50만 부담) 기준:
- +50% 매출 → 월 약 70만원
- +100% 매출 → 월 약 85만원

## 매출 증가 자영업자 — 6월부터 자금 계획

매출 큰 폭 증가했다면 7월 인상 미리 대비:

| 6월 액션 | 효과 |
|----------|------|
| 매월 적립 (인상분 비축) | 7월 부담 완화 |
| 분납 신청 사전 검토 | 통보 후 즉시 신청 |
| 노란우산·연금저축 추가 납입 | 절세 + 자금 분산 |
| 카드 활용 (납부 시 무이자) | 시점 분산 |

6월부터 매월 인상 예상분 10~20만원 적립하면 7월 큰 부담 없음.

## 7월 통보서 — 어디서 받나

새 보험료 통보 채널:

- **우편** — 사업자 등록 주소 (7월 중순)
- **모바일 통보** — 카카오톡·문자 (등록자만)
- **온라인 조회** — [국민건강보험](https://www.nhis.or.kr) 또는 모바일 앱
- **국민연금** — [국민연금공단](https://www.nps.or.kr) 또는 NPS 앱

우편 못 받았어도 온라인 조회로 확인 가능. 7월 중순까지 통보 없으면 본인 등록 주소·연락처 점검.

## 분납 신청 — 통보서 받은 후 즉시

건강보험 분납 신청:

| 신청 방식 | 처리 |
|-----------|------|
| 건강보험 홈페이지 → 분할납부 신청 | 즉시 |
| 콜센터 1577-1000 | 상담 후 |
| 가까운 지사 방문 | 동일 |

분납 횟수: 최대 10회. 별도 이자 없음. 매월 마감 전 신청해야 다음 달부터 적용.

## 시점별 6~7월 액션 — 추천 일정

D-29부터 7월 첫 납부까지:

| 시점 | 액션 |
|------|------|
| **6/4 (오늘)** | 본인 5월 신고 매출 합계 메모 |
| 6월 둘째 주 | 작년 대비 매출 증감 계산 |
| 6월 중 | 7월 인상 예상액 시뮬레이션 |
| 6월 말 | 자금 시뮬레이션 완료 |
| **7월 중순** | **통보서 수령 + 인상 폭 확인** |
| 7월 둘째 주 | 분납 신청 (필요 시) |
| 7월 25일경 | 첫 납부 |

## 분납 vs 일시납 — 자금 부담 비교

매출 큰 폭 증가 (월 보험료 70만원 가정):

| 옵션 | 매월 부담 | 자금 분산 |
|------|-----------|-----------|
| 일시납 | 70만 | X |
| 분납 5회 | 14만 × 5월 | ✅ |
| 분납 10회 | 7만 × 10월 | ✅ 최대 |

분납 10회 시 매월 7만원만 부담. 자금 분산 효과 매우 큼.

## 매출 감소 자영업자 — 자동 인하 + 추가 옵션

매출 감소 시 자동 인하 외 옵션:

| 옵션 | 자격 | 효과 |
|------|------|------|
| 자동 인하 | 매출 감소자 | 자동 적용 (별도 신청 X) |
| 납부 예외 (국민연금) | 사업 일시 중단·소득 0 | 1년 단위 유예 |
| 보험료 경감 (건강보험) | 저소득·중증질환 등 | 일부 경감 |
| 임의계속가입 | 폐업 후 직장가입자 유지 옵션 | 부담 분산 |

본인 케이스가 \"매출 급감 + 자금 어려움\" 이면 지사 상담 권장.

## 직장 → 자영업 전환 케이스 — 더 복잡

작년 중간에 직장 다니다가 사업자 등록한 경우:

- 퇴사 시점까지 직장가입자
- 자영업 등록 직후 지역가입자 전환
- 5월 종소세 = 직장 + 사업 소득 합산
- 7월 보험료 = 새 종합소득 기준 재산정

\"임의계속가입\" 으로 직장가입자 보험료 1년 유지 가능. 자영업 매출 작은 초기에 활용 가치.

자세히는 머니룩의 \"자영업자 4대보험 종소세 신고 후 변동\" 가이드 참고.

## 무신고 자영업자 — 추정 소득 부과 위험

종소세 무신고 자영업자:

- 보험료 \"추정 소득\" 으로 부과 (통상 더 높게 책정)
- 사후 적발 시 가산세 누적
- 매년 추정 누적 → 부담 폭증

따라서 매출 작아도 신고가 결과적으로 보험료에서 유리.

## 자주 발생하는 7월 보험료 실수

자영업자 7월 자주 발생하는 실수:

- **\"통보서 안 받음\" 무시** → 온라인 확인 안 함 → 가산금
- **분납 신청 시점 놓침** → 일시납 자동 처리
- **인상 폭 사전 시뮬레이션 안 함** → 7월 갑작스러운 충격
- **자동이체 미설정** → 매월 본인 직접 납부 누락
- **매출 감소 자동 인하 못 받음** → 통보서 확인 안 함

## 결론: D-29, 6월 시뮬레이션 = 7월 부담 결정

자영업자 7월 보험료 변동은 6월 사전 시뮬레이션이 결정합니다. 정리:

- 7월 중순 통보, 7월 25일 첫 납부
- 매출 증감에 따라 35~80% 변동
- 자동 인하는 별도 신청 X
- 분납 신청 최대 10회 (이자 X)
- 6월부터 자금 적립 + 시뮬레이션 권장
