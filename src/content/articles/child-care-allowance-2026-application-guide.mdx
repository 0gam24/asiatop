자녀양육수당은 어린이집·유치원에 다니지 않고 가정에서 양육하는 만 0~95개월 자녀에게 월 10~20만원 지원하는 제도입니다. 부모급여와는 다른 별도 제도로, 만 24개월 이상 자녀가 있는 가정이 가장 많이 활용합니다.

<div class="tldr">

### 핵심만 30초

- **대상**: 만 0~95개월 자녀 + 어린이집·유치원 미이용 가정
- **지원 금액**: 0~11개월 약 20만 / 12~23개월 약 15만 / 24~95개월 약 10만
- **부모급여와 다름**: 0~23개월은 부모급여 우선 (50~100만)
- **신청처**: [복지로](https://www.bokjiro.go.kr) 또는 행정복지센터
- **소득·재산 제한 없음** (가정양육 사실만 확인)

</div>

본 글의 지원 금액·자격은 보건복지부 운영 안내에 따라 변경될 수 있으니, 신청 전 [복지로](https://www.bokjiro.go.kr) 와 [보건복지부](https://www.mohw.go.kr) 공식 페이지를 재확인하시기 바랍니다. 본 글은 정보 제공 목적이며 법률 자문이 아닙니다.

## 자녀양육수당 — 자격 요건

만 0~95개월 (약 만 8세 이하) 자녀를 **가정에서 양육**하는 부모가 대상:

| 자녀 연령 | 자격 | 지원 금액 (월) |
|-----------|------|-----------------|
| 0~11개월 | ✅ (부모급여 우선) | 약 20만원 |
| 12~23개월 | ✅ (부모급여 우선) | 약 15만원 |
| 24~95개월 | ✅ | **약 10만원** |
| 96개월~ | ❌ (초등학교 진입) | — |

**핵심 조건**: 어린이집·유치원 미이용 가정. 다니면 보육료·유아학비로 별도 지원.

## 부모급여 vs 자녀양육수당 — 명확한 차이

자주 혼동하는 두 제도:

| 항목 | 부모급여 | 자녀양육수당 |
|------|----------|---------------|
| 대상 연령 | **만 0~23개월** | 만 0~95개월 |
| 월 지원 | **약 50~100만** | 약 10~20만 |
| 어린이집 이용자 | 일부 가능 | ❌ |
| 우선 적용 | 0~23개월 부모급여 우선 | 24개월+ 자녀양육수당 |

만 0~23개월은 부모급여가 훨씬 큰 혜택. 24개월+ 부터 자녀양육수당이 의미.

## 지원 금액 — 연령별 정확히

2026년 기준 (변경 가능):

| 자녀 연령 | 월 지원 (원) | 연 누적 |
|-----------|---------------|----------|
| 0~11개월 | 200,000 | 약 240만 |
| 12~23개월 | 150,000 | 약 180만 |
| 24~95개월 (만 2세~만 8세) | **100,000** | 약 120만 |

만 24개월 이상 자녀 1명 = 연 약 120만원. 만 5년 누적 = 약 600만원.

## 신청 절차 — 5분

복지로 온라인 신청:

1. **복지로 로그인** — [복지로](https://www.bokjiro.go.kr) 본인 인증
2. **양육수당 메뉴** — \"복지서비스 → 자녀 양육수당 신청\"
3. **자녀 정보 입력** — 가족관계증명서 자동 호출
4. **가정양육 확인** — 어린이집·유치원 미이용 자가 신고
5. **제출 + 지급 계좌 입력** — 본인 명의 활성 계좌

또는 가까운 행정복지센터 방문 신청 가능.

## 어린이집·유치원 등원 시 — 다른 제도

자녀가 어린이집·유치원 다니면 다른 지원:

| 시설 | 지원 |
|------|------|
| 어린이집 | 보육료 (월 약 30~70만, 시간별 차등) |
| 유치원 (공립) | 유아학비 (월 약 10~30만) |
| 유치원 (사립) | 유아학비 (월 약 30~70만) |

세 가지 (양육수당·보육료·유아학비) **중복 수령 불가**. 본인 케이스에 따라 1개만.

## 지급 시점 — 매월 25일경

신청 후 지급:

- 첫 지급: 신청 익월 25일경
- 매월 25일경 본인 계좌 입금
- 자동 처리 (별도 매월 신청 X)

예: 6월 신청 → 7월 25일경 첫 입금.

## 시설 이용 변경 — 즉시 신고 필수

자녀가 어린이집·유치원 입소·퇴소 시 즉시 신고:

| 상황 | 신고 의무 |
|------|-----------|
| 양육수당 → 어린이집 입소 | 즉시 신고 (양육수당 종료) |
| 어린이집 퇴소 → 가정양육 | 즉시 신고 (양육수당 신청) |
| 유치원 → 가정 (방학 등) | 별도 신고 X (시설 등록 유지) |

신고 누락 시 사후 환수 가능.

## 소득·재산 제한 — 없음

자녀양육수당은 소득·재산 무관:

- 고소득자도 자격 있음
- 다주택자도 자격 있음
- 단 자녀 시설 미이용 + 만 95개월 이하 조건만

다른 정부 지원 (기초·차상위) 대비 진입 장벽 낮음.

## 본인 자격 자가 진단

다음 항목 점검:

- [ ] 만 0~95개월 자녀가 있나?
- [ ] 자녀가 어린이집·유치원에 다니지 않나?
- [ ] 본인 명의 활성 계좌가 있나?

3가지 모두 \"YES\" 면 자격. 즉시 신청 가능.

## 자주 빠뜨리는 케이스

자격 있는데 신청 안 하는 흔한 케이스:

- **\"안내문 안 받음\"** → 자격 자동 적용 X, 본인 신청 필수
- **\"소득 높아 자격 없을 것\" 오해** → 소득 제한 없음
- **\"부모급여 받았으니 끝\" 오해** → 24개월 이후 양육수당 별도 신청
- **만 24개월 도래 시 자동 전환 X** → 본인 신청 필요
- **시설 변경 시 신고 누락** → 사후 환수 위험

## 만 24개월 도래 — 부모급여 → 양육수당 전환

만 0~23개월 자녀 부모급여 → 만 24개월 도래 시:

- 부모급여 자동 종료
- 양육수당 자동 전환 ❌ (본인 신청 필수)
- 가정양육 지속 + 양육수당 신청 = 월 10만 계속 받음
- 신청 누락 시 월 10만 손실

특히 \"부모급여 끝나면 그냥 끝\" 오해가 가장 큰 손실.

## 결론: 24개월~95개월 자녀 + 가정양육 = 신청 필수

자녀양육수당은 가정양육 부모에게 5년 누적 약 600만원 지원하는 제도입니다. 정리:

- 만 0~95개월, 어린이집·유치원 미이용
- 월 10~20만원 (연령별)
- 소득·재산 제한 없음
- 복지로 5분 신청
- 만 24개월 도래 시 부모급여 → 양육수당 본인 전환 신청 필수
