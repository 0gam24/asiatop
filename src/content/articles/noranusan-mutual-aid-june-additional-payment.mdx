자영업자·소상공인의 노란우산공제 6월 추가납입은 12월 세액공제 + 운용 수익 + 폐업 대비 동시 효과. **6월 분산 납입**이 12월 일시납보다 운용 기간 ↑. 6월 본인 자금 사정에 맞춰 분할 적립 권장.

### 핵심만 30초

- **월 납입**: 5만 ~ 100만 (연 1,200만)
- **세액공제**: 사업소득 4천만 이하 500만, 4~6천만 300만, 6~1억 200만
- **세액공제율**: 13.2%~16.5%
- **6월 분산** = 운용 기간 ↑ + 자금 분산
- **폐업 시 일시금 + 운용 수익** = 노후 자금 + 새 사업 자금

## 노란우산공제 — 자영업자 IRP 격

자영업자·소상공인 노란우산공제 = 자영업자판 IRP:

| 항목 | 노란우산공제 |
|------|----------------|
| 대상 | 자영업자·소상공인 |
| 월 납입 | 5만 ~ 100만 |
| 연 한도 | 1,200만 |
| 세액공제 | 소득별 200~500만 |
| 폐업 시 | 일시금 + 운용 수익 |
| 운용 수익 | 정부 보장 약 3~4% |

자영업자 노후 + 폐업 대비 동시 효과.

저소득 자영업자 = 한도 ↑ + 세액공제율 ↑.

## 6월 분산 vs 12월 일시 — 시뮬레이션

연 한도 1,200만 분할 vs 일시납:

| 방식 | 6월 운용 시작 | 운용 수익 (3.5% 가정) |

## 신청 절차 — 5단계

본인 노란우산 가입:

1. **[중소벤처기업진흥공단](https://www.kosmes.or.kr) 또는 본인 거래 은행 방문**
2. **본인 사업자등록증 + 신분증** 제출
3. **납입 한도 + 매월 자동이체 설정** — 본인 소득별
4. **본인 계좌 자동이체 시작**
5. **12월 종합소득세 신고 시 세액공제 자동 적용**

본인 사업자등록 1년+ = 가입 자격 권장.

## 자주 발생하는 6월 노란우산 실수

자주 발생하는 실수:

- **"노란우산 = 어려움" 오해** → 본인 거래 은행 5분 가입
- **"한도 = 동일" 오해** → 본인 사업소득별 한도 차등
- **12월 일시납 → 운용 기간 손실** → 6월 분산 권장
- **본인 종합소득세 신고 시 세액공제 누락** → 자동 적용 X 케이스
- **폐업 시 일시금 신청 누락** → 본인이 신청해야 환급

가장 흔한 = "한도 동일" 오해. 본인 소득 사전 점검 필수.
