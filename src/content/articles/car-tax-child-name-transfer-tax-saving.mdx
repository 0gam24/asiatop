본인 명의 자동차의 자동차세 부담 줄이려 자녀 명의 변경을 검토하는 가구는 많습니다. 그러나 **취득세·증여세·보험료** 부대 비용을 함께 따지면 절세 효과가 작은 경우가 다수입니다. 6월 결정 전 종합 점검.

<div class="tldr">

### 핵심만 30초

- **자동차세 절약** = 약 50만/연 (대형차 기준)
- **취득세** = 차량가액 7% (1억 차 = 700만)
- **증여세** = 1,000만 초과 분 신고 의무
- **보험료** = 자녀 연령·경력에 따라 변동
- **일반 케이스** = 부대 비용 > 절세 효과

## 자동차 명의 변경 — 발생 세금

자녀 명의 변경 시 발생하는 모든 세금:

| 세금 | 부담자 | 세율 |
|------|--------|------|
| 자동차취득세 | 새 명의자 (자녀) | 차량가액 7% |
| 등록세 | 새 명의자 | 약 1~5만 |
| 증여세 | 자녀 (1,000만 초과 분) | 누진 |
| 자동차세 (정기) | 새 명의자 (자녀) | 차량별 |
| 자동차 보험료 | 새 명의자 (자녀) | 연령·경력 기준 |

자녀 명의 = 자녀가 다 부담. 가족 결정 사안.

## 자동차세 절세 효과 — 시뮬레이션

3,000cc 차량 자동차세 약 100만/연 (영업용·비영업 구분):

| 본인 vs 자녀 | 자동차세 |
|---------------|-----------|
| 본인 명의 (현재) | 100만/연 |
| 자녀 명의 (변경 후) | 100만/연 |
| **자동차세 차이** | **0 (실 절세 X)** |

자동차세는 차량가액 기준 = 명의자 변경해도 같은 금액. 절세 X.

## 진짜 절세 케이스 — 매우 제한

자녀 명의 변경으로 자동차세 절세되는 케이스:

| 케이스 | 효과 |
|--------|------|
| 본인 → 친환경차 자녀에 증여 → 자녀가 친환경차 추가 등록 | 자녀 친환경차 감면 |
| 본인 영업용 차량 → 자녀 비영업용 | 일부 차종 |
| 본인 사업장 → 폐업 후 자녀 명의 유지 | 사업장 부담 종료 |

일반 가구 = 효과 작음.

## 취득세 부담 — 큰 비용

차량가액 7%의 취득세는 명의 변경 시 새로 발생:

| 차량가액 | 취득세 (7%) |
|-----------|--------------|
| 3,000만 | 약 210만 |
| 5,000만 | 약 350만 |
| 1억 | **약 700만** |
| 1.5억 | 약 1,050만 |

명의 변경 = 새 취득으로 간주 → 다시 7% 부담.

## 증여세 — 차량가액 기준

차량가액 1,000만 초과 시 자녀에게 증여세 신고 의무:

| 자녀 관계 | 10년 비과세 한도 | 1,000만 초과 분 |
|------------|---------------------|----------------|
| 미성년 자녀 | 2,000만 | 누진 (10~30%) |
| 성년 자녀 (만 19+) | 5,000만 | 누진 (10~30%) |
| 손주 (직계 비속) | 1,000만 | 누진 |

성년 자녀 = 5,000만 비과세 + 5,000만 초과 분만 증여세.

## 자녀 명의 자동차 보험료 — 변동 시뮬레이션

자동차 보험료 = 가입자 연령·경력 기준:

| 본인 vs 자녀 | 보험료 (대략) |
|---------------|------|
| 본인 45세 + 운전 경력 10년 | 약 100만/연 |
| 자녀 25세 + 운전 경력 3년 | **약 250만/연** |
| 자녀 19세 + 운전 경력 1년 | 약 350만/연 |

자녀 명의 = 보험료 ↑ 큰 부담 가능. 결정 전 시뮬레이션 필수.

## 부대 비용 vs 절세 효과 — 종합 시뮬레이션

3,000만 차량 자녀 명의 변경:

| 항목 | 금액 |
|------|------|
| 취득세 (7%) | 약 210만 |
| 증여세 (성년 자녀, 비과세 한도 안) | 0 |
| 자동차세 절약 | 0/연 |
| 자녀 보험료 증가 (10년) | 약 1,500만 |
| **총 부담 (10년)** | **약 1,700만+** |
| 절세 효과 | 0 |

일반 케이스 = 명의 변경 = 큰 부담. 절세 X.

## 자녀 명의 변경 적합 케이스 — 5가지

다음 케이스만 명의 변경 고려:

| 케이스 | 이유 |
|--------|------|
| 자녀 결혼·독립 가구 형성 | 가구 분리 자연스러움 |
| 본인 폐업 + 자녀 후속 운영 | 사업장 승계 |
| 자녀 가족 단독 사용 | 본인 운전 X |
| 본인 사망 대비 사전 증여 | 상속세 절감 |
| 자녀 친환경차 + 본인 차량 교체 | 친환경차 감면 |

위 5가지 외 일반 가구 = 명의 변경 비추천.

## 명의 변경 절차 — 7단계

본인 결정 후 절차:

1. **자녀 (또는 새 명의자) 신분증·인감** 준비
2. **본인 (현 명의자) 인감** 준비
3. **본인 거주 차량등록사업소 방문**
4. **명의 변경 신청서 작성**
5. **취득세 납부** — 즉시
6. **새 자동차 등록증 발급** — 약 1~2주
7. **자동차 보험료 가입자 변경** — 보험사 별도

약 1~2주 소요. 본인이 직접 처리 또는 등록 대행 활용.

## 자녀 미성년 — 부모 보호자 처리

미성년 자녀 (만 18세 미만) 명의 변경:

- 부모가 법정 대리인 (보호자)
- 자동차 운전 X (만 18세 이상 가능)
- 자동차세는 자녀 명의 + 부모 부담
- 증여세 신고 의무

특별한 사유 (자녀 신탁 자금 운용 등) 외 미성년 명의 변경 불필요.

## 자녀 명의 자동차 — 본인 운전 가능 여부

자녀 명의 자동차 + 본인 운전:

| 케이스 | 가능 여부 |
|--------|-----------|
| 자녀가 가족 한정 보험 가입 + 가족 운전 | 가능 |
| 자녀가 본인 단독 보험 | ⚠️ 본인 운전 시 보험 X |
| 자녀 명의 + 본인 자주 운전 | 보험 처리 미적용 위험 |

본인 자주 운전 = 자녀 명의 의미 작음.

## 본인 자동차세 절세 — 다른 방법

자녀 명의 변경 외 본인 자동차세 절세:

| 방법 | 효과 |
|------|------|
| 1월 연납 할인 약 9.15% | 자동차세 약 9만 절약 |
| 친환경차 교체 | 100% 감면 |
| 카드 무이자 할부 + 캐시백 | 1~3% 절감 |
| 영업용 등록 | 자영업자만 |

연납 + 친환경차 = 가장 효율적 자동차세 절약 방법.

## 자주 발생하는 명의 변경 실수

자주 발생하는 실수:

- **"명의 변경 = 자동차세 절세" 오해** → 자동차세는 차량 기준
- **취득세 7% 무인식** → 큰 부담 발견 시 후회
- **증여세 신고 의무 모름** → 신고 누락 가산세
- **자녀 보험료 ↑ 무인식** → 매년 부담 ↑
- **본인 운전 시 보험 처리 X** → 사고 시 막대한 손실

가장 흔한 = "절세 효과" 오해. 종합 비용 사전 시뮬레이션 권장.

## 결론: 일반 케이스 = 명의 변경 비추천

자동차 자녀 명의 변경은 절세 효과보다 부대 비용이 큰 경우가 다수입니다. 정리:

- 자동차세 = 명의 변경해도 같음
- 취득세 7% 새로 발생
- 증여세 1,000만 초과 분 신고 의무
- 자녀 보험료 ↑ (연령·경력)
- 본인 자동차세 절약은 1월 연납 + 친환경차 교체가 효율
