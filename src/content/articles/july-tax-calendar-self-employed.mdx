5월 종합소득세 마감 끝났다고 자영업자 세무 부담이 끝나는 게 아닙니다. **7~8월에 4~5가지 세무 일정**이 한꺼번에 옵니다. 부가세 7/25 + 건강보험 7월 정산 + 종소세 분납 2차 8/31 + 양도세 (해당자) 가 동시 진행. 미리 캘린더 등록이 정공입니다.

<div class="tldr">

### 핵심만 30초

- **7/25**: 부가세 1기 확정 신고 마감 (개인 일반과세자·법인)
- **7월 중순**: 건강보험·국민연금 7월 정산 통보서 발송
- **7월 말 ~ 8월 중순**: 종소세 환급금 입금
- **7/31**: 5월 매도자 양도세 신고 마감 (해당자)
- **8/31**: 종소세 분납 2차 + 6월 매도자 양도세 신고

## 7월 통합 일정 — 한눈에

| 날짜 | 일정 | 대상자 |
|------|------|--------|
| 7/1 | 지방소득세 신고 시작 (6/30 마감) | 자영업자 |
| 7월 초·중순 | 종소세 환급금 입금 시작 (5월 초 신고자) | 환급 대상자 |
| 7월 중순 | 건강보험·국민연금 7월 정산 통보 | 자영업자 (지역가입자) |
| **7/25** | **부가세 1기 확정 신고 마감** | 개인 일반과세자·법인 |
| 7월 말 ~ 8월 중순 | 종소세 환급금 입금 (5월 말 신고자) | 환급 대상자 |
| **7/31** | **양도세 신고 마감 (5월 양도자)** | 5월 매도자 |
| 8/31 | 종소세 분납 2차 | 분납 신청자 |
| 8/31 | 양도세 신고 마감 (6월 양도자) | 6월 매도자 |

7~8월에 7~8개 일정 누적. 자영업자는 5월 종소세 끝나면 곧바로 7월 부가세 준비 시작 권장.

## 7월 25일 부가세 — 5~6월부터 사전 준비

부가세 1기 확정 신고는 1~6월 매출·매입 신고:

### 사전 준비 5단계 (6월~7월)

1. **6월 초**: 1~6월 매출 자료 정리 시작 — 카드 매출·세금계산서·현금영수증
2. **6월 중**: 매입 자료 정리 — 임차료·인건비·재료비 영수증
3. **7월 초**: 모의계산 → 매출 합계가 종소세 신고와 일치 확인
4. **7월 중순**: 분납 가능 여부 (1천만 초과) 사전 확인
5. **7/20~25**: 최종 신고서 작성 + 제출

특히 **종소세 매출과 부가세 매출 일치** 가 가장 중요. 불일치 시 국세청 자동 조사 대상.

자세히는 머니룩의 [부가가치세 7/25 신고 사전 준비](/tax/vat-filing-july-25-d2month-preparation/) 가이드 참고.

## 7월 건강보험·국민연금 정산

5월 종소세 신고 매출이 7월 보험료에 자동 반영:

| 매출 변동 | 7월 보험료 변동 |
|------------|------------------|
| 매출 동결 | 변동 없음 |
| 매출 20% 증가 | 약 15~20% 인상 |
| 매출 50% 증가 | 약 35~45% 인상 |
| 매출 30% 감소 | 약 25~30% 인하 |
| 매출 50% 감소 | 약 40~50% 인하 |

### 7월 통보서 받은 후

1. 통보서 확인 → 보험료 변동액 파악
2. 분납 가능 여부 검토 (건강보험 최대 10회)
3. 자금 부족 시 즉시 분납 신청
4. 자동이체 설정 (또는 기존 변경)

자세히는 머니룩의 [종소세 신고 후 4대보험료 변동](/tax/self-employed-4-major-insurance-after-tax-filing/) 가이드 참고.

## 종소세 분납 2차 8/31 — 자동이체 권장

분납 1차 5/31 처리한 자영업자는 8/31 2차 납부:

| 옵션 | 처리 |
|------|------|
| **자동이체** | 8월 31일 자동 빠짐 (권장) |
| 본인 직접 납부 | 7월 안 캘린더 알림 + 8월 처리 |
| 미납 | 일 0.022% × 지연일수 가산세 |

7월에 \"8월 31일 알림\" 캘린더 등록 또는 홈택스 자동납부 신청 권장.

## 5월·6월 매도자 양도세 마감

| 양도일 | 양도세 신고 마감 |
|--------|--------------------|
| 5월 양도 | **7월 31일** |
| 6월 양도 | **8월 31일** |

부동산 매도자는 등기 이전일 다음 다음 달 말까지 신고. 부가세 7/25 직후 양도세 7/31 → 7월 부담 큼.

자세히는 머니룩의 [양도세 8월 신고 5월 매도자](/realestate/capital-gains-tax-august-filing-after-may-deed/) 가이드 참고.

## 종소세 환급금 입금 — 7월 초~중순

신고 시점별 입금 일정:

| 신고 시점 | 환급 입금 |
|-----------|-----------|
| 5/25 이전 | 6월 말 ~ 7월 초 |
| 5/26~28 | 7월 초 |
| 5/29~31 | 7월 중순 ~ 말 |
| 6/1 이후 (자진 수정) | 8월 ~ 9월 |

환급 입금 직후 노란우산·연금저축 추가 납입 → 내년 절세 순환 시작.

## 7월 자금 계획 — 자영업자 시뮬레이션

매출 1억 자영업자의 7월 자금 변동 예시:

| 항목 | 시점 | 금액 |
|------|------|------|
| 종소세 환급 (해당자) | 7월 초·중순 | +30~100만원 |
| 부가세 1차 납부 (1천만 초과 시 분납) | 7/25 | -500만원 |
| 7월 보험료 인상분 (해당 시) | 7/25 | -30~50만원 |
| 양도세 1차 (해당자) | 7/31 | -매도 차익에 따라 |
| 종소세 분납 2차 (해당자) | 8/31 | -신고 시 정해진 금액 |

7~8월은 자영업자에게 자금 부담 큰 시기. 5월에 미리 자금 계획 권장.

## 직장인은 7월 부담 거의 없음

직장인(근로소득자) 의 7월 일정:

- 종소세 환급 입금 (해당자) → 단순 수령
- 건강보험 7월 정산 (회사 보수 기준) → 회사가 자동 처리
- 양도세 (5월 매도 시) → 본인 처리
- 부가세 의무 없음

따라서 7월은 **자영업자에게 집중된 부담** 시기. 직장인은 환급금만 챙기면 됨.

## 8월 일정 — 종소세 분납 2차 + 다른 의무

8월에 처리할 일정:

| 날짜 | 일정 |
|------|------|
| 8월 첫 주 | 7월 보험료 정상 납부 |
| 8월 중 | 종소세 자진 수정신고 (해당자, 6/30 후) |
| **8/31** | **종소세 분납 2차 마감** |
| 8/31 | 양도세 신고 (6월 매도자) |
| 8/31 | 양도세 분납 2차 (5월 매도자) |

8월 31일이 마감 폭주일. 미리 캘린더 등록 필수.

## 9~12월 후속 일정 미리 — 종부세 포함

7월 캘린더 만들 때 함께 등록할 가을·겨울 일정:

| 날짜 | 일정 |
|------|------|
| 9/16~30 | 종부세 합산배제·1주택 특례 정기 신청 |
| 10/25 | 부가세 2기 예정 신고 (법인) |
| 11월 중순 | 종부세 고지서 발송 |
| 12/1~15 | 종부세 정기 납부 + 분납 신청 |
| 다음 해 1/25 | 부가세 2기 확정 신고 |

7월에 이 일정들도 함께 캘린더 등록하면 1년 전체 세무 일정 완성.

## D-Day (5/31) 시점 권장 액션

오늘(5/31) 종소세 마감 끝나면 즉시:

1. 신고 제출 확인
2. 환급 계좌 정확성 재점검
3. **7월 캘린더 등록** — 부가세 7/25, 보험료, 양도세 (해당자)
4. 8월 캘린더 등록 — 분납 2차, 양도세 분납
5. 9~12월 종부세 일정 등록

이 5단계만 마치면 1년 전체 세무 일정 미리 완성.

## 결론: 5월 마감 = 7월 시작 + 1년 캘린더

종소세 마감은 한 해 세무의 끝이 아니라 7~12월 후속 일정의 시작점입니다. 핵심 정리:

- 자영업자는 7~8월에 4~5개 세무 일정 누적
- 부가세 7/25 사전 준비 6월 초부터 시작
- 7월 보험료 인상 시 즉시 분납 신청
- 종소세 분납 2차 8/31 자동이체 권장
- 양도세 (해당자) 7/31 또는 8/31 별도 신고
- 환급금 입금 후 노란우산 재투입으로 절세 순환
