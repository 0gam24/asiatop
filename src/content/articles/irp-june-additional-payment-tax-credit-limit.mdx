퇴직연금 IRP는 12월 세액공제 + 노후 적립 동시 효과. **6월 추가납입**이 12월 일시납보다 운용 기간 ↑ + 본인 자금 분산 활용 가능. 6월 6개월 분할 활용 시 부담 최소화하며 같은 세액공제 달성.

<div class="tldr">

### 핵심만 30초

- **한도**: 연금저축 600만 + IRP 합산 = 연 900만 (IRP 단독 900만 가능)
- **세액공제율**: 총급여 5,500만 이하 16.5%, 초과 13.2%
- **900만 납입 = 약 119~148.5만 세액공제**
- **6월 분산 납입**: 운용 기간 ↑ + 자금 분산
- **자영업자·프리랜서도 가능**

## IRP + 연금저축 합산 한도 — 정확한 계산

소득세법 기준 합산 한도 (2026년):

| 항목 | 한도 |
|------|------|
| 연금저축 (단독) | 600만 |
| IRP (단독) | 900만 |
| **연금저축 + IRP 합산** | **900만** |

만 50세 이상 추가 한도는 2020~2022년 납입분 한시 특례였고, 2023년부터 전 연령 한도가 600만/900만으로 상향되면서 폐지됐습니다. 본인 활용 = 합산 900만 안에서 자유 분배 (단, 연금저축분은 600만까지).

## 세액공제율 — 본인 총급여별

본인 총급여 기준 세액공제율:

| 총급여 | 세액공제율 | 900만 납입 시 |
|--------|------------|----------------|
| 5,500만 이하 | **16.5%** | 약 148.5만 |
| 5,500만 ~ 1.2억 | 13.2% | 약 118.8만 |
| 1.2억 초과 | 13.2% | 약 118.8만 |

저소득 직장인 = 세액공제율 ↑. 본인 활용 적극 권장.

## 6월 추가납입 vs 12월 일시납 — 비교

같은 900만 납입 시 결과:

| 시점 | 6월 납입 | 12월 일시납 |
|------|----------|--------------|
| 운용 기간 | 약 18개월 | 약 6개월 |
| 수익 (3.5% 가정) | + 약 47만 | + 약 16만 |
| 세액공제 | 동일 약 148.5만 | 동일 약 148.5만 |
| 본인 자금 부담 | 분산 | 12월 집중 |

6월 납입 = 추가 운용 수익 + 자금 분산. 효율 ↑.

## 12회 분할 vs 1회 일시 — 시뮬레이션

6월 시작 + 12회 분할 (월 75만) vs 12월 일시납 (900만):

| 방식 | 총 운용 수익 |
|------|---------------|
| 6월 시작 + 12회 분할 (월 75만) | 약 32~39만 |
| 12월 일시납 | 약 16만 |
| **차이** | **+ 16~23만** |

분할 납부 = 자금 분산 + 운용 수익 ↑.

## 본인 케이스별 추천 활용 — 3가지

본인 직업·소득 기준:

### 케이스 1: 직장인 (5,500만 이하)
→ **세액공제율 16.5% 최대 활용**
→ 900만 납입 = 약 148.5만 환급
→ 6월 분할 시작 권장

### 케이스 2: 자영업자
→ 종소세 신고 시 세액공제
→ IRP 통한 노후 대비
→ 종소세 환급 + IRP 적립 동시

### 케이스 3: 프리랜서
→ 종합소득 기준 세액공제
→ 자유 입금 가능
→ 6월 추가납입 시 12월 신고 시 활용

## IRP 인출 가능 시점 — 만 55세+

IRP 자금 인출:

| 인출 시점 | 처리 |
|-----------|------|
| 만 55세 미만 | 중도 인출 = 16.5% 기타소득세 |
| 만 55세 + 가입 5년+ | 연금 수령 (저세율) |
| 만 65세+ | 연금 수령 (저세율) |

본인 은퇴 + 만 55세 도달 = IRP 인출 시점.

## 6월 IRP 가입 절차 — 5단계

은행 또는 증권사 IRP 개설:

1. **은행·증권사 IRP 개설** — 본인 인증
2. **운용 상품 선택** — 예금·펀드·ETF
3. **자동 이체 설정** — 매월 분할 납입
4. **추가 일시납** — 6월 별도 입금
5. **12월 종합소득세 신고 시 세액공제** — 자동 호출

은행 IRP = 안정. 증권사 IRP = 운용 자유.

## IRP 운용 상품 — 본인 위험 성향별

본인 위험 감수성 기준:

| 위험 성향 | 추천 상품 | 예상 수익 |
|-----------|-----------|------------|
| 안정형 | IRP 예금 (정기예금) | 약 3~3.5% |
| 중립 | 채권 ETF + 일부 주식 | 약 5~7% |
| 적극형 | 주식 ETF + 글로벌 분산 | 약 7~10% |

본인 노후 자금 보호 + 운용 효율 = 중립 ~ 적극 권장.

## 본인 부양 가족 + IRP — 세액공제 합산

본인 인적공제 + IRP 합산 효과:

| 본인 케이스 | 12월 환급 |
|--------------|------------|
| 부양 가족 X + IRP 900만 | 약 119~148.5만 |
| 부양 자녀 2명 + IRP 900만 | 약 119~148.5만 + 자녀세액공제 55만 (2025년 귀속 기준) = **약 174~204만** |
| 부양 부모 + IRP 900만 | 약 119~148.5만 + 부모공제 150만 + 경로우대 100만 |

본인 가족 부양 + IRP = 12월 환급 효과 매우 큼.

## 연금저축 vs IRP — 본인 활용 결정

본인 활용 선택:

| 항목 | 연금저축 | IRP |
|------|----------|-----|
| 운용 상품 | 펀드 중심 | 예금·펀드·ETF |
| 자유 인출 | 부분 가능 | 어려움 |
| 가입 조건 | 자유 | 근로자·자영업자 |
| 세액공제 | 600만 한도 | 900만 한도 (연금저축 합산) |

본인 자유 인출 원함 = 연금저축. 노후 적립 = IRP.

## 자주 발생하는 6월 IRP 실수

자주 발생하는 실수:

- **"12월 일시납이 좋다" 오해** → 운용 기간 손실
- **세액공제 한도 초과 납입** → 한도 외 효과 X
- **본인 총급여 모르고 세액공제율 잘못 계산** → 본인 급여 확인 필수
- **자영업자가 IRP 활용 안 함** → 종소세 환급 기회 손실
- **만 55세 전 중도 인출** → 16.5% 기타소득세

가장 흔한 = "12월 일시납" 오해. 6월 분산 = 효율 ↑.

## 6월 ~ 12월 분할 시뮬레이션

본인 자금 부담 분산:

| 본인 자금 | 6~12월 (7개월) 매월 | 효과 |
|-----------|---------------------|------|
| 900만 | 월 129만 | 12월 일시납 대비 + 약 17만 운용 수익 |

분할 = 자금 부담 ↓ + 운용 효율 ↑.

## 결론: 6월 시작 = 노후 + 12월 환급 동시 효과

IRP 6월 추가납입은 12월 일시납보다 운용 효율 ↑ + 자금 분산. 정리:

- IRP + 연금저축 합산 = 연 900만 (연금저축분은 600만까지)
- 세액공제율 16.5% (5,500만 이하) ~ 13.2%
- 6월 분산 = 운용 기간 ↑ + 자금 분산
- 자영업자·프리랜서도 가능
- 본인 가족 부양 시 12월 환급 효과 매우 큼
