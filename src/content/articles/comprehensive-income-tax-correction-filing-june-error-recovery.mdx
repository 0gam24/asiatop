5월 종소세 신고 후 오류·누락을 발견한 자영업자·프리랜서는 **6월 정정신고**로 회복 가능합니다. 가산세 감면 90% 시점이 6월. 자녀공제·의료비·기부금 누락 발견 시 즉시 경정청구 = 추가 환급 가능.

<div class="tldr">

### 핵심만 30초

- **수정신고** = 본인이 적게 신고 → 추가 세금 + 가산세 (감면 90%)
- **경정청구** = 본인이 많게 신고 → 추가 환급
- **6월 안 정정** = 가산세 최대 감면 (90%)
- **5년 안 가능** (국세기본법)
- **신고 자체 누락** = 기한 후 신고 (별개)

</div>

본 글의 가산세·절차는 국세기본법 운영 안내에 따라 변경될 수 있으니, 처리 전 [홈택스](https://www.hometax.go.kr) 와 [국세청](https://www.nts.go.kr) 공식 페이지를 재확인하시기 바랍니다. 본 글은 정보 제공 목적이며 세무 자문이 아닙니다.

## 정정신고 — 2가지 종류

5월 신고 후 본인 발견 오류 유형:

| 유형 | 명칭 | 결과 |
|------|------|------|
| 본인이 매출을 적게 신고 (또는 비용 과다) | **수정신고** | 추가 세금 + 가산세 (감면) |
| 본인이 매출을 많게 신고 (또는 비용 누락) | **경정청구** | 추가 환급 |
| 자녀공제·의료비·기부금 누락 | **경정청구** | 추가 환급 |
| 본인 명의 신고 안 됨 | **기한 후 신고** | 별개 절차 |

신고 종류 정확 결정 후 절차 진행.

## 수정신고 — 가산세 감면 시기별 차등

본인이 적게 신고 시 가산세 감면 (국세기본법):

| 시점 | 가산세 감면 |
|------|------|
| 6/16 ~ 7/15 | **90% 감면** |
| 7/16 ~ 9/15 | 70% 감면 |
| 9/16 ~ 12/15 | 50% 감면 |
| 12/16 ~ 6개월 | 30% 감면 |
| 6개월 ~ 1년 | 20% 감면 |
| 1년 ~ 2년 | 10% 감면 |

6월 안 자진 정정 = 최대 감면. 막판 회피 권장.

## 수정신고 시뮬레이션 — 매출 100만 누락

5월 신고 시 매출 100만 누락 → 6월 발견:

| 시점 | 추가 세금 | 가산세 (감면 적용) | 합계 |
|------|-----------|----------------------|------|
| 6월 정정 | 약 24만 | 약 2,400 (90% 감면) | **약 24.2만** |
| 12월 정정 | 약 24만 | 약 12만 (50% 감면) | 약 36만 |
| 3년 후 발견 | 약 24만 | 약 24만 (감면 X) | 약 48만 |

빨리 = 가산세 최대 감면. 6월 정정 = 30~50% 절약.

## 경정청구 — 환급 추가 케이스

본인이 많게 신고 또는 공제 누락 시 추가 환급:

| 누락 항목 | 추가 환급 |
|-----------|-----------|
| 자녀공제 누락 (1명) | 25만 (2025년 귀속 기준) |
| 자녀공제 누락 (3명+) | 95만+ |
| 의료비 (200만 초과 분) | 의료비 × 15% |
| 기부금 (지정·법정) | 약 15~30% |
| 보험료 누락 | 약 12~13% |
| 신용카드·체크카드 사용 | 본인 한도 적용 |

5월 신고 시 자료 누락 발견 = 경정청구 즉시 신청.

## 경정청구 절차 — 5단계

[홈택스](https://www.hometax.go.kr) 경정청구:

1. **홈택스 로그인** — 본인 인증
2. **"종합소득세 → 경정청구 신청"** 메뉴
3. **신고 연도 선택** — 2025년 분 (2026년 5월 신고분)
4. **수정 항목 입력** — 자녀·의료비·기부금 등
5. **제출 + 본인 명의 계좌 등록**

처리 기간: 약 2~3개월. 환급 입금 8~9월경.

## 수정신고 절차 — 5단계

추가 세금 발생 시 수정신고:

1. **홈택스 로그인**
2. **"종합소득세 → 수정신고"** 메뉴
3. **신고 연도 선택** — 2025년 분
4. **누락 매출·비용 수정** — 정확한 값 입력
5. **추가 세금 + 가산세 자동 계산** + 본인 납부

납부 즉시 = 처리 완료. 가산세 감면 자동 적용.

## 6월 정정 vs 5월 신고 차이 — 비교

| 항목 | 5월 정상 신고 | 6월 정정신고 |
|------|----------------|----------------|
| 절차 | 표준 신고 | 수정/경정청구 |
| 가산세 | 0 | 90% 감면 (수정신고) |
| 처리 기간 | 1~2주 | 2~3개월 (경정청구) |
| 환급 입금 | 6월 말 ~ 7월 | 8~9월 |

빨리 = 처리 빠름.

## 5년 경정청구 룰 — 과거 누락 회복

종소세 경정청구는 5년 안 가능 (국세기본법):

| 신고 연도 | 경정청구 가능 시점 |
|-----------|----------------------|
| 2025년 분 (2026년 5월 신고) | 2031년 5월까지 |
| 2024년 분 (2025년 5월 신고) | 2030년 5월까지 |
| 2023년 분 (2024년 5월 신고) | 2029년 5월까지 |
| 2022년 분 (2023년 5월 신고) | 2028년 5월까지 |
| 2021년 분 (2022년 5월 신고) | 2027년 5월까지 |

과거 5년 누락 자녀공제·의료비 = 6월 일괄 경정청구 가능.

## 본인 점검 — 정정 필요 5가지

5월 신고서 점검:

| 점검 | 결과 |
|------|------|
| 매출 누락 (현금·카드) | 수정신고 |
| 비용 과다 신청 | 수정신고 |
| 자녀공제 누락 | 경정청구 |
| 의료비 200만+ 누락 | 경정청구 |
| 기부금 누락 | 경정청구 |

5월 신고서 다시 점검 권장.

## 신고 자체 누락 — 6월 자진 신고 (별개)

본인 종소세 신고 자체 안 했으면 정정 X. 기한 후 신고:

| 시점 | 가산세 |
|------|------|
| 6월 자진 신고 | 90% 감면 |
| 7~9월 자진 신고 | 70~50% 감면 |
| 9월 이후 | 30%+ 감면 |
| 1년 후 | 10~20% 감면 |

기한 후 신고는 정정 X = 별개 절차. 자세히는 머니룩의 [기한 후 신고 6월 자진 처리](/tax/comprehensive-income-tax-late-filing-june-1/) 가이드 참고.

## 환급 입금 시점 — 정정 후

경정청구 신청 후 환급 입금 흐름:

| 신청 시점 | 환급 입금 |
|-----------|-----------|
| 6월 초 신청 | 8월 |
| 6월 말 신청 | 8월 말 ~ 9월 |
| 7월 신청 | 9월 ~ 10월 |
| 8월+ | 10월+ |

처리 기간 2~3개월. 본인 계좌 정확성 사전 점검.

## 자주 발생하는 정정 실수

자주 발생하는 정정 실수:

- **수정 vs 경정청구 혼동** → 잘못 신청 → 거부
- **가산세 감면 시기 무인식** → 막판 정정 → 감면 50% 만
- **신고 자체 누락인데 정정 시도** → 거부 → 기한 후 신고 별도 필요
- **5년 경과 후 발견** → 영구 손실
- **본인 명의 계좌 오류** → 환급 반송 → 정정 필요

가장 흔한 = "수정 vs 경정청구" 혼동. 본인 케이스 정확 확인 후 신청.

## 5월 신고서 사후 점검 — 항목별 체크리스트

다음 항목 5월 신고서에서 점검:

- [ ] 매출 전수 (카드·현금·계좌이체)
- [ ] 비용 전수 (사업 관련 정확)
- [ ] 자녀공제 (만 8~20세 자녀)
- [ ] 의료비 (200만 초과 분)
- [ ] 기부금 (지정·법정)
- [ ] 보험료 (저축성·보장성)
- [ ] 본인 명의 계좌

누락 발견 시 즉시 정정.

## 결론: 6월 정정 = 가산세 최대 감면

5월 신고 후 6월 정정은 가장 큰 자진 신고 효과를 만듭니다. 정리:

- 수정신고 = 추가 세금 (6월 = 가산세 90% 감면)
- 경정청구 = 추가 환급 (자녀·의료·기부 누락 회복)
- 5년 안 정정 가능
- 6월 정정 = 최대 절약 시점
- 신고 자체 누락은 기한 후 신고 별개
