에너지바우처 하절기 7월 시행 D-23 시점. **본인 가구 가구원 변경**이 있다면 6월 사전 신고 권장. 본인 가구 1인 증가 = 약 9만 추가 바우처. 6월 신청 = 7월 시행 적용 시점 안전.

<div class="tldr">

### 핵심만 30초

- **7월 1일 시행** = 하절기 에너지바우처
- **본인 1인 가구** = 약 13만
- **2인** = 약 22만, **3인** = 약 31만
- **가구원 1인 추가** = 약 9만 추가
- **6월 신청 = 7월 시행 적용**

## 에너지바우처 — 가구원별 차등

본인 가구 가구원 수별 바우처:

| 본인 가구 | 하절기 바우처 (2026년) |
|-----------|--------------------------|
| 1인 가구 | 약 13만 |
| 2인 가구 | 약 22만 |
| 3인 가구 | 약 31만 |
| 4인 가구 | 약 40만 |
| 5인 이상 | 약 49만+ |

본인 가구원 ↑ = 바우처 ↑.

## 본인 가구원 추가 케이스 — 5가지

본인 가구 가구원 변경 가능 케이스:

| 케이스 | 신청 |
|--------|------|
| 본인 자녀 출생 (2026년) | ✅ 가구원 추가 |
| 본인 결혼 → 배우자 동거 | ✅ 가구원 추가 |
| 본인 부모 동거 시작 | ✅ 가구원 추가 |
| 본인 형제·자매 동거 | ✅ 일부 케이스 |
| 본인 자녀 독립 (별도 가구) | ❌ 가구원 ↓ |

본인 주민등록 등재 = 신청 자격.

## 가구원 1인 추가 효과 — 시뮬레이션

본인 가구 1인 추가 시 바우처 변화:

| 가구원 변화 | 바우처 변화 |
|--------------|---------------|
| 본인 1인 → 2인 | + 약 9만 |
| 본인 2인 → 3인 | + 약 9만 |
| 본인 3인 → 4인 | + 약 9만 |
| 본인 4인 → 5인 | + 약 9만 |

본인 1인 추가 = 약 9만 추가 (하절기).

## 6월 신청 vs 7월 신청 — 시점 차등

신청 시점별 적용:

| 시점 | 적용 시점 |
|------|----------|
| **6월 초·중 신청** | **7월 1일 시행 즉시 적용** |
| 6월 말 신청 | 7월 중·말 적용 |
| 7월 초 신청 | 7월 중·말 적용 |
| 7월 말·8월 신청 | 8월 적용 (지연) |

빨리 신청 = 7월 즉시 적용 + 본인 가구 자금 ↑.

## 본인 자격 점검 — 5가지

본인 가구 자격 사전 점검:

| 점검 | 결과 |
|------|------|
| 본인 기초생활수급자·차상위 | 자격 ↑ |
| 본인 가구원 = 주민등록 정확 | 신청 가능 |
| 본인 명의 통장 (활성) | 입금 안전 |
| 본인 사업·소득 변동 (작년 → 올해) | 자격 변동 |
| 본인 가구 자녀·부모 출생·동거 | 가구원 추가 |

5가지 점검 = 본인 자격 + 가구원 확정.

## 본인 가구 시뮬레이션 — 시나리오별

본인 가구 변경 시뮬레이션:

| 본인 케이스 | 본인 + 가구원 추가 후 |
|--------------|------------------------|
| 본인 1인 + 자녀 1명 출생 | 2인 가구 = 약 22만 |
| 본인 2인 (부부) + 부모 동거 시작 | 3인 가구 = 약 31만 |
| 본인 3인 + 자녀 추가 출생 | 4인 가구 = 약 40만 |
| 본인 부부 + 자녀 2명 + 부모 4인 → 동거 | 6인 가구 = 약 58만+ |

본인 가구 변경 = 본인 바우처 ↑.

## 신청 절차 — 5단계

[복지로](https://www.bokjiro.go.kr) 또는 [에너지바우처](https://www.energyv.or.kr) 신청:

1. **본인 인증** — 공동인증서
2. **에너지바우처 메뉴 진입** — "복지서비스 → 에너지바우처"
3. **본인 가구원 자동 호출** — 주민등록 자동
4. **변경 가구원 추가 입력** — 자녀·부모 등
5. **신청 제출 + 본인 자료 검증** — 약 1~2주

7월 시행 전 = 6월 안 신청 안전.

## 본인 자녀 출생 → 가구원 추가 — 즉시 신고

자녀 출생 시 즉시 신고:

| 시점 | 액션 |
|------|------|
| 자녀 출생 직후 | 본인 주민등록 등재 |
| 등재 후 즉시 | 복지로 에너지바우처 가구원 추가 |
| 출생 후 1개월+ | 본인 부담 추가 (가구원 변경 누락) |
| 다음 해 신청 | 다음 해부터 적용 |

자녀 출생 → 즉시 신고 = 본인 바우처 ↑.

## 본인 부모 동거 시작 — 가구원 추가

본인 + 부모 동거 시작 케이스:

| 시점 | 액션 |
|------|------|
| 부모 동거 시작 | 본인 주민등록 등재 |
| 본인 가구원 추가 신청 | 복지로 |
| 본인 자격 재검증 | 본인 소득 ↑ 가능성 |
| 본인 바우처 ↑ 적용 | 다음 달 |

본인 + 부모 동거 = 본인 가구원 ↑ + 본인 종합소득세 인적공제 동시 활용.

## 본인 동거 부모 — 종합소득세 인적공제 동시 활용

본인 + 부모 동거 시 절세 효과:

| 항목 | 효과 |
|------|------|
| 본인 종소세 인적공제 (1인 150만) | 종소세 절감 |
| 경로우대 공제 (만 70+) | + 100만 |
| 본인 에너지바우처 가구원 추가 | + 약 9만 |
| 본인 의료비 합산 | 본인 절감 |

본인 + 부모 동거 = 다중 절세 동시 활용.

## 7월 시행 전 사전 점검 — 본인 가구 액션 5가지

본인 가구 7월 시행 사전 액션:

1. **본인 주민등록 정확 (가구원 등재)**
2. **본인 자격 재확인** (기초·차상위)
3. **본인 가구원 변경 즉시 신고**
4. **본인 명의 통장 활성 (입금 안전)**
5. **6월 안 신청** (7월 시행 적용)

5단계 점검 = 본인 7월 바우처 + 본인 가구 자금 안전.

## 자주 발생하는 신청 실수

자주 발생하는 실수:

- **"가구원 자동 호출 = 100%" 오해** → 본인 주민등록 변경 안 됨 시 누락
- **본인 자녀 출생 즉시 신고 안 함** → 다음 해 적용
- **본인 부모 동거 신고 안 함** → 가구원 ↑ X
- **6월 신청 못 함** → 7월 시행 적용 지연
- **본인 자격 재검증 안 함** → 본인 소득 ↑ → 자격 X

가장 흔한 = "자녀 출생 시 즉시 신고 X". 본인 주민등록 + 본인 가구원 동시 변경 권장.

## 본인 가구 + 동절기 (12월) 시행 — 사전 점검

본인 가구 6월 변경 후 동절기 (12월) 영향:

| 항목 | 동절기 |
|------|--------|
| 본인 가구 가구원 (12월 시점) | 자동 호출 |
| 본인 바우처 (동절기) | 본인 가구원별 |
| 7월 변경 = 동절기 자동 반영 | ✅ |

본인 6월 변경 = 7월 + 12월 둘 다 적용.

## 결론: 6월 본인 가구 점검 = 7월 시행 안전

에너지바우처 6월 본인 가구 점검은 7월 시행 적용 + 본인 자금 ↑ 핵심입니다. 정리:

- 본인 가구원 변경 (출생·결혼·동거) 즉시 신고
- 본인 가구원 1인 추가 = 약 9만 추가 바우처
- 6월 신청 = 7월 시행 즉시 적용
- 본인 + 부모 동거 = 다중 절세 동시
- 동절기 (12월) 자동 반영
