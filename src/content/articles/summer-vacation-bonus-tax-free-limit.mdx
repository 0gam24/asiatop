직장인 여름 휴가비는 회사 지급 형태에 따라 **비과세 vs 과세**가 결정됩니다. 6월 회사 지급 결정 전 사규 + 지급 명목 사전 점검이 직접 실수령 차이를 만듭니다.

<div class="tldr">

### 핵심만 30초

- **휴가비 원칙** = 근로소득(과세)
- **복리후생비 형태** = 비과세 가능 (사규 기준)
- **휴가 보너스** = 전액 과세 + 4대보험 포함
- **식대(월 20만) + 자녀양육비(월 10만)** = 별도 비과세
- **6월 지급 사전 점검** = 회사 사규 + 지급 명목

## 휴가비 — 과세 vs 비과세 결정 기준

같은 휴가비라도 지급 형태에 따라 다음과 같이 갈림:

| 지급 형태 | 과세 여부 | 4대보험 |
|-----------|-----------|---------|
| **휴가 보너스** (성과·격려금) | ✅ 과세 | ✅ 포함 |
| **휴가비** (사규 복리후생) | 사규에 따라 | 사규에 따라 |
| **휴가 지원금** (전사 일률) | ⚠️ 사규 검토 | 검토 |
| **식대 합산 명목** | 식대 한도(월 20만) 안 비과세 | X |
| **상여금 형태** | ✅ 과세 | ✅ 포함 |

핵심 = 회사 사규 + 지급 명목. 단순 "휴가비" 라고 적었다고 다 비과세 아님.

## 회사 지급 시뮬레이션 — 30만 휴가비

월급 400만 직장인 + 6월 휴가비 30만 지급:

| 지급 형태 | 실수령 (대략) | 비고 |
|-----------|---------------|------|
| 휴가 보너스 (전액 과세) | 약 24만 | 약 6만 원천징수 + 4대보험 |
| 복리후생비 (전액 비과세) | **30만** | 100% 수령 |
| 식대 합산 (한도 안) | 약 27만 | 식대 한도 적용 |

복리후생비 형태가 가장 유리. 단, 회사 사규 인정 필요.

## 회사 사규 점검 — 6월 결정 5가지

본인 회사 휴가비 비과세 여부 점검:

| 점검 항목 | 확인 방법 |
|-----------|-----------|
| 사규에 "휴가비" 항목 명시 | 회사 인사 부서 |
| 전 직원 일률 지급 | 본인 vs 동료 비교 |
| 지급 명목 (복리후생 vs 보너스) | 급여 명세서 |
| 원천징수 표시 | 6월 급여명세 |
| 연말정산 반영 | 1월 정산 시 |

위 5가지 모두 "복리후생" 으로 처리되면 비과세 가능성 큼.

## 다른 비과세 항목과 합산 — 6월 활용

6월 직장인 비과세 항목:

| 항목 | 월 한도 | 연 한도 |
|------|---------|---------|
| **식대** | 20만 | 240만 |
| **자녀양육비** | 10만 | 120만 |
| **출퇴근 차량 지원** | 20만 | 240만 |
| **사내 복지카드** | 회사별 | 회사별 |
| **휴가비** (복리후생) | 사규 | 사규 |

본인 급여명세 비과세 항목 = 사실상 절세. 6월 안 점검 권장.

## 휴가 보너스 — 4대보험 영향

휴가 보너스 = 근로소득 → 4대보험 산정 영향:

| 보험 | 산정 |
|------|------|
| 건강보험 | 보수월액 포함 → 7월 정기조정 영향 |
| 국민연금 | 보수월액 포함 → 다음 연도 영향 |
| 고용보험 | 임금총액 포함 |
| 산재보험 | 임금총액 포함 |

특히 7월 건보료 정기조정 = 작년 보수 기준. 휴가 보너스 컸으면 7월 보험료 ↑.

## 휴가비 받았을 때 본인 액션 — 5단계

6월 휴가비 수령 후:

1. **급여명세서 점검** — "휴가비" 또는 "복리후생비" 항목 확인
2. **원천징수 여부** — 비과세면 원천징수 X
3. **4대보험 영향 점검** — 보수월액 변동 여부
4. **연말정산 시뮬레이션 영향** — 과세 항목 합산
5. **회사 인사 부서 문의** — 명목 불명확 시

명목 불명확 시 = 본인 직접 인사 부서에 문의. 추후 분쟁 회피.

## 회사 지급 안 하는 경우 — 직장인 대비

회사가 휴가비 지급 안 할 때:

| 대안 | 비고 |
|------|------|
| 본인 적금·CMA 활용 | 연 5% 정도 |
| 카드사 여름 캐시백 | 본인 카드 점검 |
| 정부 여름 에너지바우처 | 일부 자격 |
| 사내 복지포인트 활용 | 회사별 |

휴가비 = 회사 정책이지만 본인 자체 대비도 가능.

## 자영업자·프리랜서 — 휴가비 대비

자영업자·프리랜서는 휴가비 X. 본인 대비:

| 항목 | 점검 |
|------|------|
| 사업장 6~8월 매출 변동 | 휴가 시즌 매출 ↓ 대비 |
| 카드사 자영업자 캐시백 | 본인 카드 확인 |
| 노란우산공제 활용 | 7월 적립 늘리기 |
| 종소세 환급 (6월 말 입금) | 휴가 자금 활용 |

자영업자는 종소세 환급 입금이 자연스러운 여름 자금.

## 사규에 "휴가비" 명시 안 됨 — 대응

회사 사규에 휴가비 항목 없으면:

- 일률 지급 X → 과세 가능성 큼
- 사내 협의 통해 사규 추가 권장
- 본인은 과세 가정 시뮬레이션

회사 협의로 "복리후생비" 명목 추가 = 전 직원 비과세 효과.

## 자주 발생하는 6월 휴가비 실수

자주 발생하는 실수:

- **"휴가비 = 자동 비과세" 오해** → 사규 + 명목 결정
- **휴가 보너스 받고 4대보험 영향 무인식** → 7월 보험료 ↑ 모름
- **급여명세 안 점검** → 원천징수 인식 못함
- **연말정산 시 누락** → 과세 휴가비 포함 안 함
- **회사 인사 부서 미문의** → 명목 불명확 그대로 진행

가장 흔한 = "휴가비 = 비과세" 오해. 회사 사규 + 명목 사전 점검 필수.

## 7월 건보료 정기조정 — 휴가 보너스 영향

작년 휴가 보너스 받았으면 7월 건보료 정기조정 영향:

| 작년 휴가 보너스 | 7월 건보료 영향 |
|-------------------|------------------|
| 100만 ↑ | 약 5,000원~1만 ↑ |
| 300만 ↑ | 약 1.5만~3만 ↑ |
| 비과세 휴가비 | 영향 없음 |

7월 건보료 사전 점검은 [홈택스](https://www.hometax.go.kr) 본인 보수월액 조회.

자세히는 머니룩의 "7월 건보료 정기조정 시뮬레이션" 가이드 참고.

## 결론: 6월 사전 점검 = 비과세 휴가비 안전 수령

여름 휴가비는 명목과 회사 사규에 따라 비과세 vs 과세가 결정됩니다. 정리:

- 회사 사규 + 지급 명목 사전 점검
- 복리후생비 형태 = 비과세 가능
- 휴가 보너스 = 전액 과세 + 4대보험 포함
- 7월 건보료 정기조정 영향 (보너스만)
- 식대·자녀양육비 등 다른 비과세 항목과 합산 점검
