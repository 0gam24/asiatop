7월 25일 부가세 1기 확정 신고 D-53. 6월 한 달 매출·매입 세금계산서 발급·수취를 분기 말 한꺼번에 정리하면 누락 발견이 어렵습니다. **매월 마지막날 점검** = 가산세 + 매입세액 공제 누락 동시 차단입니다.

<div class="tldr">

### 핵심만 30초

- **6/30 매월 점검** = 누락 1순위 차단
- **5단계 체크리스트** = 매출 발급 · 매입 수취 · 카드·현금 · 거래처 정보 · 작성일자
- **전자세금계산서 의무 대상** = 법인 + 개인 8천만+ (직전년)
- **가산세**: 지연 1%, 미발급 2%
- **홈택스 자동 호출** + 본인 장부 대조

</div>

## 매월 말 점검 = 가산세 차단의 핵심

분기 말(6/30) 한꺼번에 정리 시 발생하는 문제:

| 문제 | 손실 |
|------|------|
| 5월 매출 발급 누락 발견 늦음 | 지연 가산세 (1%) |
| 매입 세금계산서 수취 누락 | 매입세액 공제 영구 손실 |
| 거래처 사업자번호 오류 | 부실 기재 가산세 (1%) |
| 작성일자 vs 거래일 불일치 | 부실 기재 + 세무조사 위험 |

매월 점검 = 누락 발견 1순위. 6월 마지막날 30분이 7월 신고 부담 -90%.

## 5단계 점검 체크리스트 — 6/30 30분

### 1단계: 매출 전자세금계산서 발급 여부

매월 1일~말일 매출 전부 발급:

| 점검 항목 | 확인 방법 |
|-----------|-----------|
| 본인 발급 매출 전수 | 홈택스 "전자세금계산서 → 조회" |
| 발급 누락 매출 | 본인 장부 vs 홈택스 대조 |
| 거래처 사업자등록번호 정확성 | 거래처 명함·계약서 |
| 작성일자 = 거래일 | 일치 확인 |

누락 발견 시 **즉시 발급** (월 안에 = 가산세 X).

### 2단계: 매입 세금계산서 수취 여부

본인이 받은 매입 세금계산서 전수:

| 거래처 | 확인 사항 |
|--------|-----------|
| 정기 매입 (임차료·통신·전기) | 매월 발급 받았나? |
| 비정기 매입 (장비·소모품) | 영수증 vs 세금계산서 |
| 신용카드 매입 | 자동 호출 검증 |

매입 세금계산서 미수취 = 매입세액 공제 X = 직접 손실.

### 3단계: 카드 매출·현금영수증 누락

| 매출 종류 | 점검 |
|-----------|------|
| 신용카드 매출 | 카드사 자동 호출 vs 본인 매출 대조 |
| 현금영수증 발급 | 매출 누락 0 확인 |
| 현금 매출 (영수증 없음) | 본인 장부에만 있음 → 신고 누락 위험 |

현금영수증 미발급 = 가산세 20% (큰 손실).

### 4단계: 거래처 정보 정확성

| 거래처 정보 | 확인 |
|-------------|------|
| 사업자등록번호 | 정확 10자리 |
| 사업자 명의 | 폐업 사업자 거래 X |
| 주소 | 현재 영업 주소 |

폐업 사업자와 거래 시 매입세액 공제 X.

### 5단계: 작성일자 vs 실 거래일

| 케이스 | 결과 |
|--------|------|
| 작성일자 = 거래일 | 정상 |
| 작성일자 ≠ 거래일 (1~2일) | 부실 기재 가산세 위험 |
| 작성일자 다음 달 | 지연 발급 가산세 1% |

가능한 거래일 즉시 발급.

## 전자세금계산서 발급 의무 대상

부가가치세법 기준:

| 사업자 | 의무 |
|--------|------|
| 법인사업자 (전원) | ✅ 의무 |
| 개인사업자 (직전년 공급가액 8천만+) | ✅ 의무 |
| 개인사업자 (8천만 미만) | 종이 가능 (전자 권장) |
| 면세사업자 | 계산서 발급 |
| 간이과세자 (4,800만 미만) | 발급 의무 X |

의무 대상자가 종이 발급 = 가산세 2%.

## 발급 가산세 — 정확한 요율

부가가치세법 가산세:

| 위반 | 가산세율 |
|------|---------|
| 미발급 | **2%** |
| 지연 발급 (월 안) | 0.5% |
| 지연 발급 (월 초과) | 1% |
| 부실 기재 (거래처번호·작성일자 오류) | 1% |
| 종이 발급 (전자 의무 위반) | 2% |
| 종이 → 전자 미지급 | 0.3% |

매출 1억 미발급 시 200만 가산세. 매월 점검 = 회피.

## 매입세액 공제 누락 회피 — 검증 순서

매입세액 공제 = 본인이 신고에서 직접 받는 환급. 누락 시 영구 손실:

1. **본인 장부에 모든 매입 기록** (월말 결산)
2. **홈택스 "매입 전자세금계산서 조회"** → 거래처 발급 현황
3. **불일치 발견 시 거래처 연락** → 누락 발급 요청
4. **다음 달 안 발급** (지연 가산세 거래처 부담)

6/30 점검 시 6월 매입 누락 발견 = 즉시 회복 가능.

## 홈택스 점검 메뉴 — 5분

홈택스 로그인 후:

1. **"전자세금계산서 → 조회"** 메뉴
2. **본인 매출 자동 호출** — 월별·일별
3. **본인 매입 자동 호출** — 거래처별
4. **본인 장부와 대조** — 엑셀 다운로드
5. **누락 항목 표시** — 즉시 액션

5~10분 소요. 매월 1회.

## 자영업자 vs 법인 — 점검 차이

| 사업자 | 점검 주체 | 의무 |
|--------|-----------|------|
| 개인사업자 (8천만+) | 본인 또는 세무사 | 전자 의무 |
| 개인사업자 (8천만 미만) | 본인 | 권장 |
| 법인사업자 | 회계 담당 | 의무 |
| 간이과세자 | 본인 | 발급 X |

법인은 회계팀 월말 결산 + 본인이 한 번 검증 권장.

## 매월 점검 vs 분기말 정리 — 시간 비용

| 방식 | 월 시간 | 누락 발견 |
|------|---------|------------|
| 매월 점검 (5단계) | 30분 × 3개월 = 90분 | 즉시 |
| 분기말 한꺼번에 | 4~6시간 | 지연 발견 → 가산세 |

매월 점검 = 시간 절감 + 가산세 회피.

## 자주 발생하는 6월 세금계산서 실수

자주 발생하는 실수:

- **"매월 발급하면 자동 신고"** 오해 → 본인 7/25 신고 필수
- **"종이 세금계산서도 OK"** 오해 → 전자 의무 대상 가산세 2%
- **거래처 사업자번호 오타** → 부실 기재 가산세
- **카드 매출 자동 호출 신뢰 100%** → 본인 장부 대조 안 함
- **현금 매출 신고 누락** → 가산세 + 세무조사 위험

가장 큰 손실 = 현금 매출 누락. 본인 장부와 홈택스 대조 필수.

## 종소세 매출 vs 부가세 매출 일치 점검

5월 종소세 신고 매출 = 부가세 신고 매출과 일치해야 함:

| 점검 항목 | 결과 |
|-----------|------|
| 종소세 매출 = 부가세 1기 + 2기 매출 합계 | 정상 |
| 종소세 매출 > 부가세 매출 | 부가세 매출 누락 위험 |
| 종소세 매출 < 부가세 매출 | 종소세 매출 누락 → 추징 |

6월 점검 시 종소세 매출 데이터와 1~6월 부가세 매출 일치 확인.

## 매입세액 공제 — 큰 항목 5가지

매월 점검에서 놓치기 쉬운 매입세액 공제:

| 항목 | 공제율 |
|------|--------|
| 사업장 임차료 | 10% |
| 통신비 (사업용) | 10% |
| 광고선전비 | 10% |
| 사업용 소모품 | 10% |
| 사업용 차량 (영업용) | 10% |

월 사업장 임차료 500만 = 매입세액 공제 50만. 누락 시 큰 손실.

## 결론: 6/30 점검 = 7/25 신고 부담 -90%

부가세 세금계산서 매월 점검은 작은 시간 투자로 큰 손실을 막는 핵심입니다. 정리:

- 매월 말 5단계 체크리스트 (매출·매입·카드·거래처·작성일자)
- 발급 가산세 회피 (미발급 2%, 지연 1%)
- 매입세액 공제 누락 회피 (영구 손실)
- 홈택스 자동 호출 + 본인 장부 대조
- 종소세 매출과 일치 사전 점검
