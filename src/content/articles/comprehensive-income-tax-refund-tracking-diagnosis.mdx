5월 종합소득세 환급금은 6월 말 ~ 7월 중순 입금 예정. 그 사이 본인 환급 진행 상태를 추적하면 입금 지연 사유를 미리 발견·정정 가능합니다. 6월 첫 주가 추적 시작 시점입니다.

## 환급 진행 4단계 — 단계별 의미

홈택스 \"환급금 조회\" 화면의 단계별 의미:

| 단계 | 의미 | 통상 다음 단계까지 |
|------|------|----------------------|
| **접수** | 신고서 정상 접수 | 1~3일 |
| **심사 중** | 국세청 환급 적정성 검토 | 2~4주 |
| **승인** | 환급액 확정 | 1~2주 |
| **입금** | 본인 계좌 입금 완료 | 즉시 표시 |

### 시점별 정상 단계
- 5/25 이전 신고자: 6월 첫 주 = \"심사\" 또는 \"승인\"
- 5/26~28 신고자: 6월 첫 주 = \"심사\"
- 5/29~31 신고자: 6월 첫 주 = \"접수\" 또는 \"심사\"
- 6월 자진 신고자 (기한 후): 6월 둘째 주 \"접수\"

## 6월 1일 (오늘) 추적 시점

오늘 6월 1일 환급 진행 단계 확인:

1. 홈택스 로그인
2. \"신고/납부 → 환급금 조회\" 메뉴
3. 본인 신고서 표시 확인
4. 현재 단계 확인

\"접수\" 표시 = 정상 (신고 후 1~3일 내). \"심사\" 표시 = 정상 (이미 검토 시작). 표시 안 됨 = 신고 실패 가능성 → 즉시 재신고.

## 환급 입금 시점 — 신고 시점별

신고 시점별 환급 입금:

| 신고 시점 | 환급 입금 |
|-----------|-----------|
| 5/25 이전 | **6월 말** |
| 5/26~28 | 7월 초 |
| 5/29~31 | 7월 중순 ~ 말 |
| 6월 자진 신고 (기한 후) | 7월 말 ~ 8월 |

본인 신고 시점 기준 위 일정 안 입금되면 진단 필요.

## 입금 안 들어올 때 — 5가지 사유 진단

환급 안 들어오는 흔한 사유들:

### 1. 계좌 오타 (가장 흔함, 80%+)
- 신고서 작성 시 계좌번호 1자리 틀림
- 은행 시스템 입금 거부 → 국세청 반송
- 진단: 홈택스 \"환급 계좌 정확성 재확인\"

### 2. 폐쇄 계좌
- 작년 신고 시 자동 호출된 계좌가 폐쇄
- 본인이 모르고 그대로 입력
- 진단: 은행 앱에서 계좌 활성 상태 확인

### 3. 가족 명의 계좌
- 본인 인식 부족으로 배우자·자녀 계좌 입력
- 본인 명의 외 거부
- 진단: 통장 명의 확인

### 4. 외화 계좌
- 외화 계좌 (USD·EUR 등) 입력
- 원화만 가능
- 진단: 계좌 종류 확인

### 5. 동결 계좌
- 신용·세금·법적 사유로 본인 계좌 동결
- 입금 자체 차단
- 진단: 은행에 동결 여부 문의

## 정정 신청 — 4단계

위 5가지 사유 발견 시 정정:

1. **홈택스 로그인** — [홈택스](https://www.hometax.go.kr)
2. **세금신고 → 환급 계좌 정정** 메뉴 진입
3. **본인 명의 활성 원화 계좌 재입력** — 통장 확인 필수
4. **제출 + 처리 대기** — 통상 2~4주 추가 처리

정정 신청 후 환급 재처리. 빨리 정정할수록 입금 빠름.

## 7월 말까지 미입금 — 즉시 액션 5단계

7월 말까지 입금 없으면 즉시:

1. **홈택스 환급금 조회** — 어느 단계에서 멈췄는지 확인
2. **계좌 정확성 재확인** — 본인 명의·활성·원화
3. **국세청 콜센터 (126)** — 진행 상황 문의
4. **세무서 방문** — 필요 시 (사후 적발 케이스 가능)
5. **정정 신청** — 계좌 문제면 즉시

## 환급 단계별 처리 시간

각 단계별 통상 처리 시간:

| 단계 | 평균 | 최대 |
|------|------|------|
| 접수 → 심사 진입 | 1~3일 | 1주 |
| 심사 → 승인 | 2~4주 | 6주 |
| 승인 → 입금 | 3~7일 | 2주 |

예상 시간 + 50% 지나도 다음 단계로 못 가면 진단 필요.

## 환급 빨리 받는 사후 팁

이미 신고 끝났어도 환급 빨리 받는 팁:

- **환급 계좌 정확성** = 본인 계좌 자주 사용하는 거 (폐쇄 X)
- **추가 자료 요청 시 즉시 응답** — 국세청 자료 요청은 통상 카카오톡·이메일
- **세무서 콜백 우선 응답** — 적극 협조 시 처리 빠름

자주 사용 본인 계좌 = 입금 거부 위험 거의 없음.

## 추가 납부 케이스 — 분납 1차 처리 확인

환급 아닌 분납 신청자도 6월 1일 점검:

- 5/31 1차 납부 처리 확인 (가상계좌면 6/2 처리 가능)
- 8/31 2차 자동이체 설정 확인
- 분납 신청 누락 시 일시 납부로 자동 전환됨

홈택스 \"납부 내역 조회\" 에서 확인 가능.

## 자주 발생하는 실수

환급 추적 시 자주 발생하는 실수:

- **\"자동 입금되겠지\" 무관심** — 계좌 오류 시 본인 정정 필요
- **\"7월 첫 주 안 들어옴 = 지연 X\"** — 신고 시점에 따라 7월 말도 정상
- **환급 진행 단계 무시** — 진단 시점 놓침
- **\"국세청이 알아서 처리\"** — 본인 책임 영역도 있음
- **세무대리인에게만 의지** — 본인 직접 확인 권장

특히 \"자동 처리\" 오해가 위험. 본인 계좌 정확성은 본인 책임.

## 결론: 6월 첫 주 = 환급 추적 시작점

종소세 환급은 자동 처리되지만 계좌 정확성·진행 추적은 본인 책임입니다. 정리:

- 6월 첫 주 = 환급 진행 단계 추적 시작
- 4단계 (접수·심사·승인·입금) 의미 이해
- 7월 말까지 미입금이면 즉시 진단
- 5가지 사유 (계좌 오타·폐쇄·가족 명의·외화·동결)
- 정정 신청 빠르게 = 입금 빠름
