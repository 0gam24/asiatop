고유가 피해지원금 신청 마감 7월 3일까지 D-30. 소득 하위 70% 가구가 대상이며, 본인 자격 모르고 신청 안 하는 케이스가 가장 큰 손실입니다. 6월 안 신청 권장.

<div class="tldr">

### 핵심만 30초

- **마감**: **7월 3일** (D-30)
- **자격**: 소득 하위 70% 국민
- **판정 기준**: 본인·가구 건강보험료
- **사용처**: 에너지 관련 비용 + 일부 생활비
- **신청처**: [복지로](https://www.bokjiro.go.kr) 또는 행정복지센터

</div>

본 글의 자격·기준은 산업통상자원부·국민건강보험공단 운영 안내에 따라 변경될 수 있으니, 신청 전 [복지로](https://www.bokjiro.go.kr) 와 공식 발표 페이지를 재확인하시기 바랍니다. 본 글은 정보 제공 목적이며 법률 자문이 아닙니다.

## 소득 하위 70% — 건강보험료 기준

건강보험료 기준 자격 판정 (2026년 기준):

### 직장가입자 (회사 보수 기준)
| 가구원 수 | 건보료 한도 (월) |
|----------|---------------------|
| 1인 가구 | 약 18만원 |
| 2인 가구 | 약 30만원 |
| 3인 가구 | 약 40만원 |
| 4인 가구 | 약 50만원 |
| 5인 이상 | 약 55~70만원 |

### 지역가입자 (소득·재산 기준)
| 가구원 수 | 건보료 한도 (월) |
|----------|---------------------|
| 1인 가구 | 약 12만원 |
| 2인 가구 | 약 22만원 |
| 3인 가구 | 약 32만원 |
| 4인 가구 | 약 42만원 |

본인 건보료 = 한도 안 = 자격. 정확한 한도는 매년 변경.

## 본인 자격 자가 진단 — 30초

본인 가구 자격 빠른 점검:

1. **본인 직장가입자인가, 지역가입자인가?**
2. **본인·배우자 건보료 합산 = 한도 안인가?**
3. **가구원 수는?**

위 3가지 입력하면 [복지로](https://www.bokjiro.go.kr) 모의계산기로 즉시 자격 자동 판정.

## 사용처 — 에너지 + 일부 생활비

지원금 사용처 (지자체 운영 기준 다소 차이):

| 카테고리 | 사용 가능 여부 |
|----------|-----------------|
| 전기요금 (한국전력) | ✅ |
| 가스요금 (도시가스) | ✅ |
| 기름 (등유·경유·휘발유) | ✅ |
| 식료품 (대형마트·편의점) | ⚠️ 일부 가능 |
| 의료비 | ⚠️ 일부 가능 |
| 사치품·유흥 | ❌ |
| 카드 현금화 | ❌ |

본인 거주 지자체 운영 기준 확인 필수.

## 지원 금액 — 가구원 수별

가구원 수별 지원 금액 (2026년 기준, 정확한 금액은 출시 시):

| 가구원 수 | 1회 지원 금액 |
|----------|---------------|
| 1인 | 약 15~25만원 |
| 2인 | 약 25~40만원 |
| 3인 | 약 35~55만원 |
| 4인 이상 | 약 45~70만원 |

정확한 금액 + 매월 vs 일시 지급은 지자체별 차이.

## 신청 절차 — 4단계

복지로 온라인 신청:

1. **복지로 로그인** — [복지로](https://www.bokjiro.go.kr) 본인 인증
2. **고유가 피해지원금 메뉴** — \"복지서비스 → 고유가 지원금 신청\"
3. **자격 자동 판정** — 본인 건보료·가구 정보 자동 호출
4. **신청서 제출 + 지급 계좌 입력** — 본인 명의 활성 계좌

또는 가까운 행정복지센터(주민센터) 방문 신청 가능.

## 직장인·자영업자·프리랜서 — 모두 가능

자격 종류별 가능 여부:

| 본인 유형 | 자격 |
|-----------|------|
| 직장인 (회사 다님) | ✅ (직장가입자 보수 기준) |
| 자영업자 | ✅ (지역가입자) |
| 프리랜서 (3.3%) | ✅ (지역가입자) |
| 무직·휴업 | ✅ (가구 합산) |
| 학생 (부모 부양) | ✅ (가구 합산) |

본인 단독 vs 가구 합산 = 가구 합산 기준이 통상 적용.

## 신청 후 지급 시점

신청 후 지급 일정:

| 단계 | 소요 시간 |
|------|-----------|
| 신청 접수 | 즉시 |
| 자격 심사 | 약 2~4주 |
| 지급 결정 | 1~2주 |
| **본인 계좌 입금** | **신청 후 약 4~6주** |

6월 초 신청 → 7월 중순 ~ 말 입금 가능.

## 마감 직전 7월 1~3일 — 트래픽 폭증 회피

마지막 3일 (7/1~3) 신청 시 위험:
- 복지로 시스템 지연·다운 가능성
- 행정복지센터 방문자 폭주
- 신청 누락 위험

6월 안 처리가 가장 안전. 본인 자격 6월 초 점검 → 6월 중 신청 권장.

## 자주 빠뜨리는 케이스

자격 있는데 신청 안 하는 흔한 케이스:

- **\"안내문 안 받음\"** → 자격 있어도 본인이 신청 안 하면 X
- **\"중산층이라 자격 없음\" 자의 판단** → 소득 하위 70% = 중산층 다수 포함
- **\"신청 절차 복잡\" 우려** → 복지로 5분 신청
- **\"몇 만원 안 됨\" 무관심** → 4인 가구 70만원 가능
- **마감 직전 신청** → 시스템 다운 위험

특히 \"중산층 자격 없음\" 자의 판단이 가장 큰 손실. 본인 자격 정확히 모름.

## 마감 후 7/3 이후 — 영구 소실

7/3 마감 후:
- 그해 신청 영구 소실
- 다음 해 (2027) 별도 정책 발표 시 재신청
- 사후 청구 룰 없음

따라서 **올해 자격자는 7/3 안 신청 필수**.

## 결론: D-30, 6월 안 자격 점검 + 신청

고유가 피해지원금은 본인 자격 판정 + 빠른 신청이 정공입니다. 정리:

- 7/3 마감, 오늘 D-30
- 소득 하위 70% = 건보료 기준
- 본인·가구 자격 [복지로](https://www.bokjiro.go.kr) 즉시 모의 판정
- 6월 안 신청 권장 (7월 초 트래픽 폭주 회피)
- 신청 후 약 4~6주 본인 계좌 입금
- 직장인·자영업자·프리랜서 모두 가능

본 글의 자격·기준은 변경될 수 있으니 신청 전 [복지로](https://www.bokjiro.go.kr) 와 [산업통상자원부](https://www.motie.go.kr) 공식 안내를 재확인하시기 바랍니다. 본 글은 정보 제공 목적이며 법률 자문이 아닙니다.
