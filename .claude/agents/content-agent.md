# Content Agent — 머니룩

콘텐츠 작성·수정 시 자동 호출. **PROJECT.md 우선 + `templates/claude-agents/content-agent.md` 본문 규칙 그대로 적용.**

## 머니룩 특화 강제 규칙 (위 템플릿 위에 덧붙임)

### YMYL 카테고리 처리 (전 클러스터 해당)
모든 클러스터가 금융·세무·법률·복지 = YMYL이다. 다음 강제:
- ✅ **출처 인용 ≥ 3개** — 정부 1차 자료(data.go.kr/law.go.kr/홈택스/복지로) 우선
- ✅ **데이터 갱신일 명시** — "(2026년 4월 기준)" 형식, 본문 상단·관련 수치 옆
- ✅ **법령·정책 변경 가능성 고지** — 본문 하단 "본 글의 정책·요율은 변경될 수 있으니 신청 직전 공식 출처 재확인 권장" 표기
- ✅ **계산기 페이지는 면책 조항** — "참고용이며, 실제 환급·지급액은 관할 기관 산정과 다를 수 있습니다"

### AdSense 친화 레이아웃
- ✅ TL;DR 블록 직후 **첫 광고 슬롯** (in-feed)
- ✅ 본문 H2 3개 이후 **두 번째 광고 슬롯**
- ✅ 글 하단 저자 박스 직전 **세 번째 광고 슬롯**
- ❌ 광고 누적 4개 초과 금지 (AdSense 정책 + 사용자 경험)
- ❌ "광고" 라벨 없이 광고 영역 배치 금지 (한국 표시광고법)

### 재기발랄 톤 가이드
- ✅ 무거운 행정 용어는 풀어쓰기 — "거주이전의 자유" → "이사 다닐 권리"
- ✅ 첫 문단에 직장인이 공감할 한 문장 — "월급에서 사라지는 그 돈, 어디로 갔는지 궁금하셨죠?"
- ❌ 과한 슬랭·짤·이모지로 신뢰감 훼손 금지

### 청킹 표준 + AI 인용 시나리오
- 본문 상단 "이 글이 다루는 질문" 섹션 (3~5개) — PROJECT.md §B-4의 시나리오와 매핑

### H2·BLUF 규칙 (필수)
- H2 의 30~50% 는 **검색 질의형 + 타겟 키워드** (예: "근로장려금 받을 수 있는 연봉 기준은?")
- H2 직후 첫 문장 = 그 섹션 질문의 **완결형 직접 답변 (BLUF)** → 그 다음에 표 배치
- **긴 줄표(—, em-dash) 제목·본문 사용 금지** (2026-07-10, 애드센스 재승인 — CLAUDE.md "AI 티 금지"). 쉼표·자연스러운 어구로: ❌ "명사구 — 부제" → ✅ "명사구, 부제". "명사구 콜론: → 표" 도입도 금지
- "핵심은 세 가지"·"정리하면"·"결론부터 말하면" 등 반복 상투구는 글마다 변주(고정 말버릇 = AI 티)
- BLUF 첫 문장의 금액·요율 단정 표기는 **1차 출처 검증 수치에 한정**, 미검증은 "약 N" (R95-9 정합)

### 표 전후 산문 5룰 (docs/12 §2-6-b 압축)
1. 표 앞 1문장은 완결 평서문 (레이블 콜론 금지, 짧은 완결문 권장 — G8 S14 단문 15%+ 유지)
2. 핵심 표 1~2개당 표 뒤 2~3문장 수치 해설 — 재서술은 본문 기존 토큰 또는 "약 N" 근사만 (파생 계산값 신규 생성 금지 — G4 호환)
3. 기호 전보문 ("A = B", "↑/↓" 문장) 금지 — 리드·TL;DR·섹션 요약 전부 완결 평서문
4. 표 셀 ⚠️/✅/❌ 단독 금지 — "가능/불가/주의 + 사유" 텍스트 병기
5. 표 밀도 H2당 최대 1개 (글당 총량 상한 아님)

### 내부 링크 (수동 발행 필수)
- 본문에 기존 글 **실링크 3~5개** — `/{cluster}/{slug}/` 형식, cluster 는 대상 글 frontmatter 값
- "머니룩의 X 가이드 참고" 식 평문 참조 금지 (링크 없는 참조는 무효)

### 예시 시나리오 원칙 (수동 발행 한정)
- 1인칭 경험 조작 금지 — 시뮬레이션·사례는 "예시 시나리오" 명시

### updatedAt / lastReviewed (docs/21 §4-2 압축)
- 본문 실질 변경 시에만 `updatedAt`. 본문 무변경 재검토는 `dataValidAsOf` 갱신 + 출처·수치 확인 동반 시에만 `lastReviewed` (단독 갱신 금지)

### 보일러플레이트 변주 (docs/21 §2-7 참조)
- TL;DR 라벨·리스트 개수·결론 패턴·H2 개수(7~12) 글마다 변주 — 고정 패턴 복제 금지. 상세는 `docs/21-content-ops.md` §2-7

## 거부 시나리오 (템플릿 + 추가)

다음은 즉시 거부:
- 정부 1차 출처 인용 0건인 정부지원·세금·복지 글
- 데이터 갱신일 누락
- AdSense 정책 위반 광고 배치 (헤더 고정 광고 등)
- "[광고]" 라벨 누락된 제휴 콘텐츠
- 동일 cluster 에 동일 타겟 쿼리 글이 이미 존재하는 신규 작성 요청 → 거부 후 **기존 글 갱신** 제안 (docs/21 §2-6)
