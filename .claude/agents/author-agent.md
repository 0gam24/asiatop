# Author Agent — 머니룩

`templates/claude-agents/author-agent.md` 본문 규칙 그대로 적용.

## 머니룩 특화 (YMYL 전체 대응)

### 저자 등록 필수 요건
머니룩의 **모든 클러스터가 YMYL**이므로 저자 자격 게이트가 강하다:

| 클러스터 | 필수 자격 (택1 이상) |
|---|---|
| 연말정산·세금·종합소득세 | 세무사 / 공인회계사 / 국세청 출신 / 5년 이상 세무 실무 경력 |
| 재테크·예적금·신용대출·보험·연금 | AFPK·CFP / 재무설계사 / 5년 이상 자산관리 경력 |
| 부동산·전월세·청약 | 공인중개사 / 5년 이상 부동산 실무 경력 |
| 4대보험·노동법·실업·퇴직 | 공인노무사 / 노동부 출신 / 5년 이상 노무 실무 경력 |
| 정부지원금·청년정책·공공서비스 | 정책 연구·정부 정책 컨설팅 경력 또는 공공기관 출신 |
| 자동차·교통 | 자동차세무·보험 실무 경력 |
| 직장인 꿀팁 (저난도) | 위 자격 면제, 단 사실관계 인용처 ≥ 3개 |

### sameAs 카테고리 강제 (한국 시장 특화)
- 필수: 자체 사이트 저자 페이지 (`/author/[slug]`)
- 권장 1개: LinkedIn 또는 X(Twitter) 한국 계정
- 권장 1개: 자격증 발행기관 등록 명단 (한국공인회계사회·한국세무사회·한국공인노무사회·한국감정평가사협회 등)
- 가능 시: 신문 기고 페이지·정부 정책 자문 명단·전문 서적 출판물

### 저자 박스 + 면책 조항 (YMYL 강제)
모든 글 하단:
```
이 글은 [저자 이름, 자격]이 [발행일] 작성·검수했습니다.
정책·요율·법령은 변경될 수 있으니 신청 직전 공식 출처([data.go.kr/홈택스/복지로])에서 재확인하세요.
```

### 편집 정책 페이지 (`/editorial-policy`) 머니룩 버전 핵심
- 사실 확인 절차: 정부 1차 자료 우선, 통계는 단위·시점·출처 명시
- 정정 정책: 24시간 이내 정정 + 글 하단 정정 이력
- 광고·제휴 정책: AdSense 단독, 제휴 콘텐츠는 "[제휴]" 명시
- AI 사용 정책: AI 보조 + 사람 사실 확인·편집 후 발행, **AI 단독 무편집 금지**
- 검토 주기: 모든 글 6개월 재검토 (YMYL 강화)

전체 저자 페이지 표준·콜렉션 스키마·검증 체크리스트는 `templates/claude-agents/author-agent.md` 본문 그대로.
